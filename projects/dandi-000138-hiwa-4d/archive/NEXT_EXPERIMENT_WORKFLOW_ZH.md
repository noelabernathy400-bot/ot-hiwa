# 下一次 HiWA / Soft-GCOT 实验的标准工作流（从 DANDI 吸取的经验）

**用途**：下次更换主数据集时使用的实验协议模板。本文是**未来执行指南，不是假装已完成的结果**。先判断要解决什么科学问题、数据能否承载该问题，再做全面模型比较。2026-11-19 冻结。

## 0. 先写研究问题、对象与拒绝条件，再找数据

主研究问题可表述为：

> 当源/目标分组存在重叠或不确定性、跨域样本对应在训练时不可见时，Soft-GCOT 相对于 Hard-HiWA，能否得到更准确、更稳健的**双层组—样本最优传输关系**？

**先确认**研究目标到底是下列哪一个：（A）仅使两个边缘分布接近；（B）恢复真实组对应；（C）恢复真实逐样本或物理状态对应；（D）迁移下游任务标签。这四者的评价不同。目标不是将现有数据强行画成一张“对齐成功”的漂亮图。

**数据采纳门槛**：明确源/目标的变量含义与测量单位；有真实共同因素或可验证的语义/组关系；有足够独立试次/受试者；训练时可隐藏标签，测试时仍可获得真值；允许计算合理的跨域代价。若只有边缘分布而没有任何可验证的对应，不能声称恢复了跨域实体关系。

## 1. 数据清点、清洗与信息防火墙

1. 保存官方来源/版本/下载链接、许可、SHA256、通道名称、单位、事件时间对齐、异常和缺失审计。**原始信号与抽取的训练样本数分开写。**
2. 在最开始确定 train / development-val / locked-test，按真实独立单位（trial、session、subject）拆分。所有 PCA/FA/标准化/聚类/温度、阈值、参数选择只用训练或训练内验证，不能每失败一次就查看最终测试集。
3. 对两域分别独立拟合 Hard 标签 \(g_X,g_Y\) 和 Soft 隶属度 \(A_X,A_Y\)，绝不把源域真实同步标签写给目标训练。训练索引的真实对应与评价真值物理隔离。
4. 保存逐点原始索引、train试次、原始单位变换和随机种子，测试物理评价必须能返回原始坐标系。

## 2. **任何 OT 训练之前必须做的数据适用性检查**

先绘制**全量点云**、特征方差/协方差谱/独立KMeans与GMM簇分布，报告簇数、轮廓系数、组质量不平衡、软隶属熵、每簇有效样本数；不要先从高维挑一张“最好看”的 Fisher 图替代全维统计。

再根据预期 OT 结构做两个检验：
- **公共几何可行性**：若使用全局正交 \(R\)，它会保留所有源域成对距离 \(\|x_i-x_j\|\)。有真实同步验证样本时，先看两域同步样本距离矩阵的相关性、邻域保持、簇中心距离结构、谱差异；注意时滞、噪声、单调但非等距关系可能导致低相关。**低相关意味着这种受限正交假设可能失败，不代表神经与运动毫无联系。**
- **语义可验证性**：如果要声称真组/真物理对应，必须有独立的真值或可检验的代理约束，并事先规定组间 P 的成功定义。没有真值时，只能报告分布对齐，不能用热力图的块结构冒充组正确率。

**停止门槛（建议）**：若既没有与原始任务相关的外部匹配指标，也没有合理共同几何，而且拟合无法稳定通过数值检查，应停止这组数据上的“Soft 优势”实验，换数据或改问题假设。不要反复挑角度、美化散点图。

## 3. 模型和基线要在观察结果之前冻结

- 无变换 Identity、随机合法运输/随机检索：验证指标基线，不是有意义的模型。
- **SA**（Subspace Alignment）：适合检测单纯子空间对齐是否足够，不含层级 P/Q。
- **WA**（Wasserstein Alignment）：标准无分组 OT+全局正交对齐，检验层级结构是否必要。
- **DAD**（Density Alignment）：只在找到可核对的官方实现时宣称“原版”；改写为密度KL/网格旋转的版本必须在名称上标为 DAD-like/改编，并与源算法并列披露差异。
- 原作者 **Hard-HiWA** 与**同求解器 Hard one-hot**：区分算法核差异和分组机制差异。
- **Soft-GCOT**：仅允许相对同核 Hard 做纯软分组效果归因；源与目标分别拟合真正软概率，不以 argmax 重新喂给 Soft 优化器。
- HiWA-SSC / HiWA-GMM、CORAL、ICP 等为可选扩展：只有在实际训练、相同 split 和正确复现后才填入“实测方法表”。不得引用 Hyser 数值作为新数据成绩。

为每个模型固定训练窗数/簇质量/随机数预算/实际停机条件，保存所有失败种子；多方法使用**相同物理验证数据、同一个随机基线和对应预算**。若算法优化变量不同，只比较共同外部指标，并独立披露其内部目标，不可把不同层级目标值硬排名。

## 4. 先通过正向与数值门槛，再做主实验

在明确存在真实共同结构的控制数据上检查算法能否识别组/样本对应；这只是**求解器的单元测试**，不是论文主线的真实数据结论。输出完整 P/Q/R、局部与全局正交矩阵、ADMM原始与对偶残差、组/样本边缘误差、末轮目标、是否触达迭代上限，且不得把停机条件等同全局最优。

真实数据的主实验遵守：
1. 只改动一个因素：Hard vs Soft 的分组方式；共享基础特征、训练样本池、求解器、预算和验证规则。
2. 采用多个独立真实 trial/session + 多个 seed，报告每试次配对差异、置信区间或自助法区间，不把相邻 20ms 窗口当成独立被试。
3. 完整报告簇级 \(P\)、簇对成本矩阵 \(C\)、真实条件 \(Q^{k\ell}\)、层级运输 \(T\)、完整带熵 \(J\)、共同参考层级与无层级自由 \(W_2^2\)；对跨方法不同组测度/熵基线不得按原生 \(T/J\) 绝对值断言强弱。
4. 评价“真实对应”时采用固定、物理可解释的容差/类别/检索指标，预先注册随机与恒等基线，区分真实状态正确率与几何覆盖率。
5. 若原始测试集被多次查看，应设定**新试次或新会话**作最终盲验证；无法得到新数据则结果只称探索性，不宣称推广。

## 5. 必须预先计划的**参数—性能曲线**

这里明确区分 **调模型参数** 与 **调评分阈值**。

| 横轴 | 纵轴 | 实验目的 | 约束 |
|---|---|---|---|
| 组重叠 \(\rho\)（清晰→模糊） | 真组匹配正确率、真实样本/物理命中率、Soft−Hard 成对效应 | **最直接验证 Soft 处理模糊边界的价值** | 需要有可控制/验证真实组对应的数据；DANDI 这轮未运行 |
| 软温度 \(\tau\)（预定网格如0.25/0.5/1） | 真实对应、共享参考层级运输、数值收敛率 | 识别过硬/过软的性能变化 | 目标软分组须在目标训练集上**独立拟合**；不可使用历史泄漏 τ 图作正式证据 |
| 组数 \(K\)（例如3、4、5、6） | 真实匹配、运行时间、组质量平衡、收敛 | 检验K可辨识和粒度 | 同一内验证选择K，外部测试不调 |
| ADMM罚 \(\mu\)、熵正则 \(\epsilon_s,\epsilon_g\) | 共识与对偶残差、P/Q边缘误差、匹配和外部成本 | 判断性能受算法还是解的数值状态影响 | 不能只取收敛种子中最漂亮的结果 |
| 特征维度 \(d\) / PCA或FA | 原始物理指标、训练方差损失、内域共形性 | 评估降维值不值得 | 不跨维度直接比较原生 \(W_2^2\) |
| **评分容差** \(r\)、\(\theta\) | Hit@r、Hit@θ及随机曲线 | 展示鲁棒性与实际阈值敏感度 | **不是训练参数**；不可通过放大阈值夸大模型改善 |

**画曲线方法**：冻结横轴取值后，各点采用同一完整实验协议和真实数据重复；叠加 Hard/Soft/WA 等相同评价范围的曲线，显示各点的有效重复次数、标准差/置信区间、是否通过残差审计。最关键的是纵轴 \(\Delta(\rho)=\mathrm{Acc}_{Soft}(\rho)-\mathrm{Acc}_{Hard}(\rho)\) 的区间，检验其是否随 \(\rho\) 增长而稳定增大。**DANDI 从未实测这条组重叠曲线，本次不虚构数据点。**

## 6. 可视化：图是用来回答问题，而不是制造效果

- 第一轮是**原始全维**数据的多视角散点/分布图、尺寸与相对群体结构；第二轮按训练独立 KMeans 或 Soft 隶属度绘制**训练前**分组图。
- 同一批物理样本若要使用“统一颜色”供后验参照，严格在**全部模型训练结束后**另建绘图专用标签，绝不可回写目标训练聚类；训练时源/目标簇编号互不指代。
- Hard/Soft 的训练簇颜色要分别保持四种（或K种）；Soft 用 argmax 上色必须写明**仅用于展示**，内部真实计算仍是连续权重。
- 只有将源、目标变换到**共同坐标基**才可叠加；源/目标分别训练的 Fisher2/3 子空间本身坐标不同，不能直接叠加判读。
- Fisher 判别图要写出其目标函数与训练集：它本来最大化训练伪簇的分离度，因此不能当作数据天然簇清晰的证据；OT/NN 全维评价不能在漂亮的二维上重新计算。
- 组级 P 和样本级 \(\Gamma\) 的热力图只能解释概率质量在哪流动；若没有真实组/运动真值基线与统计检验，不能用漂亮块结构宣称具有物理意义。

## 7. 最终每个实验必须交付与决策

交付代码/commit、原始数据来源与hash、分割ID、训练与评分完全隔离证明、每种子的模型输入与P/Q/R或无P/Q声明、每步残差、随机基线、全局和共享层级成本、真实误差、失败记录、原始结果JSON/CSV、独立图表、被否定的假设与未完成项。

决策只能有三类：**有证据可继续**（超基线且收敛稳定，验证范围明确）、**仍需补充检查**（模型或样本量限制）、**停止当前数据主线**（缺乏可识别结构/外部效果）。禁止为了完成预设正面故事而删掉失败结果、事后换阈值或跨数据集偷换模型成绩。
