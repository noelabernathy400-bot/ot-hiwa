# 下一阶段实验计划：特征、簇意义、跨域匹配与位置/速度成功率

**记录：2026-11-18；状态：计划，尚未实施新实验。** 原严格无监督结果和所有归档数值保持不变。

## 一、核心问题

研究问题A：现有神经潜在特征是否形成与运动学相关的簇结构，且源域/目标域分布是否可以由低维正交几何匹配？
研究问题B：在相同特征和物理评价标准下，Soft-GCOT的簇软隶属度是否优于Hard-HiWA与不分簇WA，尤其是在边界模糊时？

## 二、用户已确定的研究修改

1. **PCA4 vs FA4**：仅换神经域降维（训练集拟合），维度均为4，保留原4D目标手部位置x/y+速度vx/vy；控制其余参数。FA不是必然优于PCA。之后单独探讨FA3/运动三维等维度成对方案。
2. **子空间/流形几何**：诊断四维空间中是否具有低于4维的局部结构；对比线性子空间和Isomap等非线性嵌入，参照原HiWA的低维嵌入→原公共维度投影。不可把仅供可视化的二维坐标投影冒充完整训练特征，不可把2D神经与4D运动直接正交对齐。必须只在训练数据拟合降维/邻域模型。
3. **事后解释自动聚类**：源域和目标域分别独立聚类（Hard KMeans / Soft prototypes），真实运动标签不进入拟合。拟合后检查神经簇、运动簇与运动目标方向、瞬时速度方向、速度大小和运动阶段的关系，作簇×行为混淆矩阵、Soft隶属度等。区分最终目标方向和瞬时速度方向。已知方向标签分组如另做实验，须独立标为半监督positive control。
4. **增加速度方向指标**：评价跨域匹配的目标手部速度向量是否符合真实运动；计算夹角、中位/平均夹角、预先设定的角度容差命中率、运动方向类别迁移准确率。接近零速度时方向不稳定，预先用训练数据确定低速排除或单独汇报规则。
5. **新增位置预测/匹配命中率**：根据匹配到的目标手部样本取位置向量，与真实同步手部位置比较二维欧氏误差，报告均值、中位数及容差内命中率。位置容差用真实物理尺度，先核对原NWB的pos系列单位；如果未核验单位，先将容差预先定义为训练集典型运动位移的固定比例（例如5%、10%、20%），禁止按测试结果挑选阈值。

## 三、“预测”的准确含义：采用用户偏好的跨域匹配评价，而不是先训练监督速度/位置回归

**保留400训练试次与100独立测试试次：**17500全部/域，14000训练/域，3500测试/域。原始每次OT训练抽样仍是各域四组各40，总160/域，后续320等预算需另做独立消融。

**训练阶段（严格无配对）**：分别使用训练源域和目标域特征、独立簇训练HiWA/GCOT，学习全局正交R、组传输P和簇内Q。训练时不得使用源点i对应目标点i的真实同步索引或运动方向标签。

**测试阶段（跨域目标检索库）**：固定训练得到的R。在留出的3500个目标域观测特征中，对每个留出源神经点寻找最近邻：
\[
\widetilde x_i=x_iR^\top,\qquad
j^*(i)=\arg\min_{j\in\mathcal T}\|\widetilde x_i-y_j\|_2^2,\qquad
\widehat y_i=y_{j^*(i)}.
\]
此处测试目标库允许使用目标特征向量，但**不允许使用源/目标真实同步关系决定最近邻**。这是转导式跨域检索或样本匹配，并不是仅输入神经点就生成连续运动的新监督解码器。

**后验物理评价**：模型和匹配均冻结以后，使用原NWB真实同步记录的目标运动 \(y_i^{true}\) 作为评分真值：
- 位置误差 \(e_i^{pos}=\|\widehat p_i-p_i^{true}\|_2\)，命中率 \(A_{pos}(r)=N^{-1}\sum_i\mathbf 1[e_i^{pos}\le r]\)；
- 速度角误差 \(\theta_i=\arccos(\langle\widehat v_i,v_i^{true}\rangle/(\|\widehat v_i\|\|v_i^{true}\|))\)，有意义速度的角度阈值命中率、方向类准确率；
- 速度大小误差、位置/速度原始物理坐标MAE/RMSE、同步真配对检索Recall@1/Recall@K（若真同步点非唯一合理匹配需标注局限）；
- 用已匹配目标点运动方向标签，比较对应神经点的运动方向标签，取得原作者演示一类的1NN跨域标签迁移准确率。方向类别标签**只参与最终评分**。
- 在手部标准化或目标域几何变换后，**必须逆变换回同一原始手部物理坐标计算所有物理容差和误差**。

### 不应把“最近邻误差很小”直接叫作预测成功

由于最近邻 \(j^*\) 本来就是为了最小化嵌入空间距离而选出来的， \(\|\widetilde x_i-y_{j^*}\|\) 很小只能说明空间中存在接近的目标候选点，**不能证明找对了对应的手部运动**。须使用独立保留的真实对应时刻的手部位置、速度、方向评分，并与随机检索、恒等变换、WA等基线比较。

### 应区分两种匹配器

- **主评价：冻结R后的全局1NN最近邻**，与原作者PyHiWA Notebook的跨域1NN分类精神接近；这里实际调用的是R，不直接调用训练Q和P，Hard/Soft差异经R间接体现。
- **后续附加：分层P-Q导出的总样本级传输计划Gamma，再从每个源点选最大运输质量目标或重心**。若在留出目标数据上重求Q，这属于转导式测试匹配，固定R/P不得测试重训练，须与1NN分开汇报。重心匹配不一定对应真实观测点。
- 可额外检验200或500个固定留出候选上的1-to-1 Hungarian/OT匹配（避免普通1NN多源复用同一目标）；不应把大规模3500x3500稠密Hungarian当成无成本。

## 四、原作者原有评价究竟是什么

原作者的 PyHiWA Notebook 在猴运动方向示例里，用最近邻在对齐后神经域与运动域之间传递**方向类别标签**。其计算是：在已对齐神经点中建立近邻索引，对运动点找最近神经点，再比较两边的伸手方向标签。它不是预测连续位置/速度，也不是对每一个神经点与原时间同步运动点直接最小二乘拟合。作者演示将两域已知方向标签作为各自分簇输入，后续簇间P仍自由学习。我们保持无监督主实验标签隔离，并新增与其方向标签迁移相似的评估。

## 五、基线、先后顺序与严格比较

- **立即可做（不重新训练）**：原PCA4、已归档Hard和Soft seed42–46的R，直接在独立3500测试点上计算跨域1NN匹配，位置/速度容差及方向类准确率；另外列出恒等R、随机候选、平坦WA等基线（WA需独立拟合）。然后评价自动簇的运动语义。
- **下一步**：仅PCA4→FA4，同一目标4D、同一评价和预算。再单独研究低维Isomap/作者式3D运动嵌入；不要同时修改多个因素。
- **最终主表**：WA、Hard、Soft，五随机种子与固定相同试次/候选池、统一容差、完整数值收敛审计。特征/簇质量与目标变换的修改作为独立消融，不混入原无监督基线。
- 注意：测试集上的位置/速度标签或同步信息**不得反向调训练、方向阈值、降维维度、时延和模型选择**。若要决定这些，在训练试次内部建立验证试次。步长20ms，若存在神经与运动时滞，须另外作为时间对齐假设的独立实验，不能直接用测试数据挑最优时滞。
- 原始4D同步点的直接R²是强假设的额外诊断，不应替代方向迁移与位置匹配命中率；分布OT代价也不等于匹配的物理正确性。
