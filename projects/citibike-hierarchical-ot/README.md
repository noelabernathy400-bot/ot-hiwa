## 核心研究问题

当站点具有真实车辆盈余和缺口、区域划分存在不确定性时，固定地理空间与实际调运费用，**Soft双层P/Q运输能否相对Hard区域分组，以更低的分层近似损失、更少资源、更好的时间稳定性，生成有效的车辆分配计划？**

固定 R=I，即取消原 HiWA 的跨域正交旋转学习部分。算法的核心是组级 P 和条件样本级 Q。此方案是**层级 OT 的城市调度适配**，不是原 HiWA 的原样复现。

**数学基线必须说清楚**：相同供需边缘、容量约束与线性运输成本下，精确平坦 min-cost flow 达到真正全局最小成本。Hard/Soft无法在同一可行域内得到严格更小的纯线性费用；评价应重点看**相对精确OT的 gap、运行时间/内存、整数调运可执行性、边界软度和扰动鲁棒性**。

## 双层运输的正确质量边缘

车站可调盈余 a_i≥0，需补缺口 b_j≥0。对于软隶属矩阵 A_ik,B_jl，各行和均为1：

α_k = Σ_i a_i A_ik，β_l = Σ_j b_j B_jl；

组级 P 的真实行/列边缘为 α 和 β，而不是早期 HiWA 固定的1/K。组内Q^(kl)的边缘为 a_i A_ik/α_k 与 b_j B_jl/β_l。重构总体运输：

Γ_ij = Σ_kl P_kl Q^(kl)_ij。

如果两域总质量不同，必须引入明确费用的虚拟仓库/缺口或非平衡OT，**不能各自默默归一化再把分数称为实际运输辆数**。实际车辆调运还需整数化和站点容量约束。

## 所有要求的基线（包含SA/WA/DAD，但不虚构适用性）

| 方法 | 在本任务的角色 | 有效比较项 |
|---|---|---|
| 精确 flat min-cost flow | 同一费用/容量下的全局最低调度成本 | 费用最优性 gap、资源、时间 |
| Flat Sinkhorn（WA-I） | 固定R=I的 Wasserstein Alignment；退化为平坦熵OT | 公共费用、时间、可执行性 |
| Greedy / nearest feasible | 可执行贪心调度 | 费用、未满足率、运行时间 |
| Hard hierarchical P/Q | 硬区域划分，原始真实边缘，R=I | 共享运营成本、gap、速度与稳定性 |
| Soft hierarchical P/Q | 边界多区域概率隶属，其他条件与Hard相同 | 同上；Soft−Hard配对效应 |
| SA | 原版Subspace Alignment对齐子空间，不直接求调运。如果加入SA特征提取+OT，必须标为**SA+OT适配版** | 统一最终可执行调度与真实运营成本 |
| DAD | 原版Density Alignment对齐密度/几何，不能在固定经纬度下任意旋转物理车站；如采用需求行为特征+OT，应标为**DAD-like+OT适配版** | 同一真实地理费用/约束；不冒充官方DAD |

**绝不能**把Hyser的SA/WA/DAD分数借来做城市对照，也不能宣称R=I下原SA/DAD仍是有意义的原算法。原方法若不能经过合理适配，就应在实验结果列出“无直接适用定义”，而非填虚构值。所有方法正式训练之前冻结成本、质量约束、共享评估和算力预算。

## 预注册的规模与参数曲线

- 城市全域、跨多个月份；站点规模以真实活跃供需站点数为准。研究n∈{250,500,1000,2000,全量}（超过真实可用数则说明缺项）；不是抽160个站点冒充大规模。
- 时间窗包括工作日晨峰、晚峰、周末和非峰时段；统计单位是独立日期/时间段，而不是同一天不同随机优化seed。
- K∈{4,8,12,24} 的分组规模及温度、熵参数，运行时长、内存、费用gap、供需欠配额、车辆调运边数、扰动后方案波动和严格数值残差。性能选择只用训练/7月内部验证，8–9月锁定。
- 不许通过调大物理阈值或删掉失败seed得出“Soft优势”，也不得期望增大数据自动提高Soft的相对性能。
