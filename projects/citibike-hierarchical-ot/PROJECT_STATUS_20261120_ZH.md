## 二、模型/基线进度，不要把未来计划写成已做结果

| 模型 | 角色 | 真实城市OT求解进度 |
|---|---|---|
| 精确 flat min-cost flow | 相同线性费用与容量的全局最优成本参照 | **未运行** |
| Flat Sinkhorn / WA with R=I | 不含层级的熵正则OT；原WA去掉旋转后即退化到此 | **未运行** |
| Greedy / nearest feasible | 同一供需边缘和容量的可执行启发式 | **未运行** |
| Hard hierarchical P/Q，R=I | 硬站点分区的层级运输 | **未运行** |
| Soft hierarchical P/Q，R=I | 边界连续隶属度层级运输；主要研究对象 | **未运行** |
| SA + OT 适配版 | SA本是子空间对齐，不能直接在固定实地成本下算运输计划 | **未定义/未运行**，必须事先解释适配的科学必要性 |
| DAD-like + OT 适配版 | 原DAD为几何/密度对齐，不能声称固定经纬度下的旋转就是调度 | **未定义/未运行**，严禁冒充原版DAD |

**正确原则：同一需求/费用/容量下精确平坦最小费用流是最小运输成本下界，Hard/Soft不可能取得更低的同一纯线性目标值。** 正式论文可比较的是 Hard/Soft 的近似成本 gap、规模扩展、时间/内存、方案稀疏性与时间扰动稳健性等。不能为了同时放入 SA/WA/DAD 而将不相干任务名称硬贴到结果上。

## 三、下一步按顺序做的科研任务（尚未执行）

1. **库存与骑行流量对表**：站点标识 \`nuid\` 与 \`station_id\`/名称的位置映射；核对两套历史数据时区和采样间隔、容量 \`slots\` 的合理性、车辆计数与空位差异；按不同日期/时间抽多快照，不能仅凭同日两个时刻确认统计规律。优先用真实库存+训练期骑行流预测设定可解释、可复核的**研究假设目标库存**，明确不等于运营方真值。
2. **构造多个可执行调运实例**：单时刻库存/预计需求/安全库存→源节点和目标节点及整数辆质量、真实站点容量，定义不平衡处理、仓库/缺口惩罚，固定地理/道路费用；复核没有凭空生成或消失车辆。
3. **先跑标准问题的精确平坦 min-cost flow 与 Greedy/Flat Sinkhorn**：设定可行性、成本最优差距和运行预算，作为不可回避的基线。
4. **再跑共享运输边缘的 Hard/Soft 双层 P/Q（R=I）**：K值与分组温度只在训练/7月内部验证选择、无人工跨域对应泄漏；正确处理不均匀分组总质量，报告 P 和 Q 的边缘残差、可执行整数方案与成本 gap。
5. **SA/WA/DAD 的可比性决策**：WA-I和Flat Sinkhorn不重复计成绩。SA/DAD若有合理站点行为特征变换且能带来运输质量变化，则显式记为 SA+OT/DAD-like+OT 适配版；无法合理定义则报告不适用，不得称原版成绩。
6. **规模/温度/簇数曲线**：实际节点规模（如250/500/1000/2000/全量，须先核对有效供需站数量）、K=4/8/12/24、熵与软温度、不同天不同窗口；报告可行解、总费用（相对精确最优的gap）、运行时间、内存、调度边数和扰动稳定性。训练/内验冻结后才看2026-08/09最终测试月份。

## 四、现阶段正式科学判断

**真实数据量已经足够庞大、具备空间区域结构，历史库存字段也确实存在；但还没有任何城市Hard/Soft/SA/WA/DAD的真实调运效果。** 最主要的未解决问题不再是找数据，而是**把观测库存与人为目标库存、真实骑行行为和可执行调运约束之间的关系定义清楚，并先建立flat最优性参照**。
