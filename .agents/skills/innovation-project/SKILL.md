# 大创项目专项

## 触发边界

只在大创项目或用户明确要求大创材料时使用。不要影响其他项目类型。

## 工作流

1. 明确选题、背景、意义和预期贡献。
2. 写清研究目标和创新点。
3. 建立阶段计划、交付物和责任分工。
4. 持续维护实验记录和阶段进展。
5. 准备立项书、中期材料、结题报告和答辩展示。
6. 保存证据：资料、数据、代码、图表、会议记录和审批材料。

## 常见产出

- 立项书
- 阶段报告
- 实验记录
- 结题报告
- 答辩 PPT
- 项目复盘
