# 图表制作

## 何时使用

- 需要论文图、结果表、流程图、模型框架图、Mermaid 图或展示图。

## 工作流

1. 明确图表要回答的问题。
2. 选择图表类型：折线、柱状、散点、热力图、箱线图、流程图、结构图、表格。
3. 保证标题、单位、图例、注释和数据来源完整。
4. 保存原始图表文件和导出版本。
5. 在论文或报告中写对应图表说明。

## 输出位置

- 项目 `Experiments/figures/`
- 项目 `Writing/图表清单.md`
- 必要时沉淀到 `Research/Presentations/`

## 质量标准

- 图表服务论点。
- 不堆装饰。
- 坐标轴和单位清楚。
- 可复现生成。
- 黑白打印也能理解。
