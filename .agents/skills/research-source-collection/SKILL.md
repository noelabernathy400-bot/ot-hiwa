# 资料搜集

## 何时使用

- 为研究项目、数学建模、课程论文或毕业论文搜集资料。
- 整理网页、PDF、数据集、开源代码、官方文档、竞赛题目和附件。

## 工作流

1. 明确搜集目标：背景、模型、数据、代码、论文、政策或案例。
2. 优先使用可靠来源：官方文档、论文、教材、比赛官网、数据源、权威机构。
3. 每条资料记录来源、标题、链接、访问日期、用途和可信度。
4. 原始资料放入项目 `Sources/` 或 `Research/Sources/`。
5. 资料摘要放入项目 `Notes/`、`Literature/` 或 `Research/Literature/`。
6. 可复用资料沉淀到 `Domains/` 或 `Research/`。

## 输出

- 资料清单
- 资料可信度分级
- 可用/不可用原因
- 下一步阅读或数据处理建议

## 安全边界

- 不下载来源不明的可执行文件。
- 不把未经核验的网页内容当作事实。
- 不覆盖原始资料。
