# 状态维护与交接

## 何时使用

- 开始或结束一次重要工作会话。
- 更新项目状态、任务清单、决策记录、操作报告、复盘和 AI 交接说明。

## 会话开始

1. 阅读 `AGENTS.md`。
2. 阅读 `README.md`。
3. 阅读全局状态、任务、决策和最近报告。
4. 如果处理具体项目，阅读项目内的状态、任务、决策和交接说明。

## 会话结束

- 更新状态。
- 记录关键决策。
- 补充下一步任务。
- 重要改动写操作报告。
- 交接说明保持短而准。

## 报告格式

- 日期
- 目标
- 改动文件
- 关键决定
- 风险或跳过事项
- 下一步
