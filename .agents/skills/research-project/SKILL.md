# 研究项目管理

## 何时使用

- 启动、整理、推进、复盘任何研究项目。
- 项目类型包括数学建模、大创项目、课程论文、科研训练、毕业论文和其他项目。

## 建议项目结构

- `Overview.md`：项目概览
- `Status.md`：项目状态
- `Task List.md`：任务清单
- `Decision Log.md`：决策记录
- `Handoff Note.md`：交接说明
- `Sources/`：原始资料
- `Notes/`：过程笔记
- `Experiments/`：实验记录
- `Writing/`：写作材料

## 工作流

1. 明确项目类型、交付物和截止时间。
2. 写清研究问题、范围、目标和限制。
3. 连接文献、方法、数据、实验和写作笔记。
4. 持续维护状态、任务和决策。
5. 将可复用内容提炼到 `Domains/` 或 `Research/`。

## 边界

- 项目特有规则留在项目内。
- 数学建模规则只影响数学建模项目。
