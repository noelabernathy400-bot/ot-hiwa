# Obsidian 知识库维护

## 何时使用

- 创建或整理 vault 中的 Markdown 笔记。
- 创建模板、MOC、双链、frontmatter、操作报告。
- 判断内容应该放入 `Projects/`、`Domains/`、`Research/`、`Templates/`、`MOCs/` 或 `Entities/`。

## 工作流

1. 先阅读 `AGENTS.md` 和相关状态文件。
2. 写入前检查目标文件是否已存在。
3. 按内容性质分类。
4. 重要概念、项目、方法、数据集、文献尽量使用 Obsidian 双链。
5. 需要检索或聚合时添加简洁 frontmatter。
6. 重要操作完成后，在 `System/Reports/` 写操作报告。

## 安全边界

- 不删除原始资料。
- 不覆盖已有文件。
- 不修改日记正文，除非用户明确确认。
- 批量移动、删除、重命名时说明范围并保留可追溯记录；用户明确请求时可直接执行。
