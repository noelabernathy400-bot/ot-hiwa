# 复现性审计

## 何时使用

- 实验完成后。
- 写论文前。
- 提交数学建模论文前。
- 交接项目给新 agent 或队友前。

## 工作流

1. 检查原始数据是否保留。
2. 检查代码、notebook、参数、随机种子是否记录。
3. 检查图表和表格能否追溯到实验记录。
4. 检查论文中的结论能否追溯到数据、模型或文献。
5. 记录无法复现的部分和修复建议。

## 输出

- 复现性检查清单
- 缺失文件列表
- 风险等级
- 修复任务

## 通过标准

- 新 agent 只读项目文件即可知道如何复现主要结果。
- 关键图表有来源。
- 关键参数有记录。
- 论文结论有证据链。
