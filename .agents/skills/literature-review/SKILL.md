# 文献综述与文献笔记

## 何时使用

- 整理论文、PDF、网页、书籍或课程资料。
- 建立文献笔记、综述矩阵、可复用观点和引用材料。

## 工作流

1. 保留原始资料或 URL。
2. 按 Zotero / Obsidian 分工处理文献：Zotero 管“文献是谁、在哪、怎么引用”，Obsidian 管“文献对研究意味着什么”。
3. 通用文献笔记放入 `Research/Literature/`；项目私有文献可放入项目文件夹。
4. 记录题名、作者、年份、来源、DOI、链接、Zotero citation key 和阅读状态。
5. 提炼研究问题、方法、数据、发现、证据和局限。
6. 区分直接引用和自己的转述。
7. 链接相关项目、方法、数据集和领域概念。
8. 可复用观点沉淀到 `Domains/` 或 `Research/Methods/`。

## Zotero / Obsidian 分工

| 材料状态 | Zotero | Obsidian |
| --- | --- | --- |
| 随手搜到、暂不确定有用 | 不必立即加入 | 记录到联网资料索引或待筛选清单，并标注“待核验” |
| 确认会读或可能引用 | 加入 Zotero，保存 DOI、URL、PDF、元数据和 citation key | 可建立简短候选记录，说明为什么可能有用 |
| 已阅读并进入论证链 | 保留 Zotero 条目、PDF、注释和稳定 citation key | 建立文献笔记、综述矩阵、证据链和项目引用表 |

使用原则：

- Zotero 是可信来源库和引用源，优先保存文献条目、PDF、DOI、作者、年份、期刊、BibTeX、原文注释。
- Obsidian 是研究理解和写作网络，优先保存阅读笔记、方法总结、证据链、项目结论、写作材料和双链关系。
- 重要 Obsidian 文献笔记应记录 Zotero citation key、DOI 或 Zotero 链接，方便从理解回到原始来源。
- 不把所有搜索结果都塞进 Zotero；只有确认会读、可能引用或需要长期管理的文献才进入 Zotero。
- 未进入 Zotero、未被 `refcheck` 或原文核验的资料，在 Obsidian 中必须标注“待核验”。

## 安全边界

- 不编造文献信息。
- 不确定的信息标注为“待核对”。
- 原文引用保持简短，并尽量记录页码。
