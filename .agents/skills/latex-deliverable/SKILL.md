# LaTeX 交付

## 何时使用

- 写数学建模论文、课程论文、毕业论文或科研报告。
- 需要 LaTeX 模板、公式、图表、参考文献、附录和编译检查。

## 工作流

1. 确认目标格式、页数、字体、模板和截止时间。
2. 建立 `Writing/` 下的 LaTeX 文件结构。
3. 先生成大纲和符号说明，再写正文。
4. 公式、图表、引用和附录分模块管理。
5. 编译后检查错误、警告、交叉引用、图片路径和参考文献。
6. 输出最终 PDF 前做终稿审查。

## 检查项

- 公式编号和引用正确。
- 图表路径正确。
- 参考文献真实且格式统一。
- 附录代码和正文一致。
- 摘要、关键词、符号说明完整。

## 安全边界

- 不编造参考文献。
- 不为了排版改动研究结论。
