# 实验记录

## 何时使用

- 规划或记录实验。
- 记录数据清洗、模型运行、仿真、评估、可视化过程。
- 保留可复现实验信息。

## 工作流

1. 明确项目、数据集、方法和实验目标。
2. 写出假设或预期结果。
3. 记录环境、代码版本、输入文件、参数和随机种子。
4. 记录结果、图表和观察。
5. 区分“结果”和“解释”。
6. 写清复现步骤和下一步。

## 安全边界

- 不覆盖旧实验记录。
- 失败实验也要保留。
- 原始数据只链接，不直接修改或删除。
