# 研究方法笔记

## 何时使用

- 记录可复用研究方法、数学模型、统计方法或算法框架。
- 比较方法的适用条件、假设、步骤、评价指标和局限。

## 工作流

1. 判断方法是项目私有还是可复用。
2. 跨项目方法放入 `Research/Methods/`。
3. 属于某个领域的知识放入 `Domains/`。
4. 记录用途、适用场景、不适用场景、前提假设、输入输出、步骤、评价方式和局限。
5. 链接相关文献、实验、数据集和相近方法。

## 好的方法笔记应包含

- 什么时候用。
- 什么时候不用。
- 需要什么数据和假设。
- 常见失败方式。
- 如何评价结果。
- 必要时给出最小示例。
