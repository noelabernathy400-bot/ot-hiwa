# 课程论文专项

## 触发边界

只在课程论文项目或用户明确要求课程论文写作时使用。

## 工作流

1. 记录课程要求、题目、字数、引用格式和截止日期。
2. 明确研究问题和中心论点。
3. 建立小型文献矩阵。
4. 制定大纲和写作计划。
5. 按章节起草。
6. 修改论证、证据、引用和格式。

## 质量检查

- 中心论点清楚。
- 每一节都服务论点。
- 文献引用准确。
- 有回应反方观点或局限。
- 格式符合课程要求。
- 终稿满足字数和截止时间。

## 安全边界

- 不编造参考文献。
- 如果有教师要求，原文保留，不随意改写。
