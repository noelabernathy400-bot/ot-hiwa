# Local skill notes

These files are optional research aids, not permission gates or mandatory routing rules.

- Use a skill only when it materially helps the current task.
- The current user request and `AGENTS.md` override any local workflow preference.
- Local skills must not force a particular external agent, mandatory report, confirmation loop, or file layout.
- Keep skills that improve reproducibility, source verification, modeling, analysis, or writing; remove obsolete workflow constraints when they slow research.
