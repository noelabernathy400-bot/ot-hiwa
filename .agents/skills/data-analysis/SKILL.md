# 数据分析

## 何时使用

- 清洗、检查或说明数据。
- 做探索性分析、统计分析、建模、可视化和结果解释。
- 为研究项目准备图表、指标和结论。

## 工作流

1. 确认数据位置，保留原始数据。
2. 先写数据说明，再做大量处理。
3. 记录清洗步骤和假设。
4. 建模前做基本探索和质量检查。
5. 指标选择要服务研究问题。
6. 将结果写入实验记录和写作材料。

## 检查清单

- 数据来源和使用限制明确。
- 缺失值已检查。
- 异常值和重复值处理有记录。
- 变量含义清楚。
- 训练、验证或测试方案有说明。
- 图表标题、单位、说明完整。

## 安全边界

- 派生数据不能冒充原始数据。
- 不要悄悄删除行或列。
- 所有排除规则都要记录。
