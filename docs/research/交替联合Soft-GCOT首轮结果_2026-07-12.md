# 交替联合 Soft-GCOT 首轮结果

_2026-07-12 · 96×96 MiHiA 子集上的最小联合优化验证_

---

## 🔎 结论

第一版交替联合优化可以稳定运行：所有三种子均收敛，六次 prototype 更新均成功，且每次的联合目标与跨域 prototype 代价都下降。没有观察到空组或 prototype collapse。

但这次更新**没有提升**固定 Soft-GCOT 的方向准确率，并使平均 movement $R^2$ 从 $0.0362$ 小幅降至 $0.0332$。因此，这一版本证明了“OT-aware prototype update”在工程和数值上可行，但尚未证明它对当前下游对齐任务有效。

## 🧪 固定实验合同

| 项目 | 设置 |
|---|---|
| 数据 | MiHiA 固定 96×96 子集 |
| 种子 | 100, 101, 102 |
| 方法 | Hard HiWA、fixed Soft-GCOT、alternating Joint Soft-GCOT |
| 软组支持 | full support |
| Soft-GCOT 协议 | $0.25 \rightarrow 0.35 \rightarrow 0.50$，Hard warm start |
| 联合外循环 | 最多 3 轮 |
| 排除项 | ROCA、sparse approximation、组件条件项、标签拟合 |

联合更新的 Block B 固定上一轮 Soft-GCOT 的组传输 $P$ 与全局旋转 $R$，优化两域 prototypes：

$$
L = L_{\mathrm{rec}}^X + L_{\mathrm{rec}}^Y
  + \lambda_{\mathrm{cross}}\widetilde L_{\mathrm{cross}}
  + \lambda_H L_{\mathrm{entropy}}
  + \lambda_2 L_{\mathrm{L2}},
$$

其中：

$$
L_{\mathrm{cross}}
= \sum_{k,l} P_{kl}\lVert R c_k^X-c_l^Y\rVert^2.
$$

跨域项按初始值归一化，因此固定的 $\lambda_{\mathrm{cross}}=0.10$ 不会由两域坐标尺度直接决定。

## 📊 结果

| 方法 | 收敛 | 平均 accuracy | 平均 movement $R^2$ |
|---|---:|---:|---:|
| Hard HiWA | 3 / 3 | 0.3715 | 0.0289 |
| Fixed Soft-GCOT | 3 / 3 | 0.3750 | 0.0362 |
| Joint Soft-GCOT | 3 / 3 | 0.3750 | 0.0332 |

相对 fixed Soft-GCOT，Joint Soft-GCOT 的三个 accuracy 差值均为 $0$。这不是因为优化没有执行：第一轮 prototype 更新将联合目标从约 $0.5072$ 降到约 $0.4953$，并将跨域 prototype 代价从约 $322$ 降到约 $295$；第二轮仍有较小下降。

| 诊断 | 观察 |
|---|---|
| Prototype 更新成功 | 6 / 6 |
| 最小源组质量 | 约 0.205 |
| 最小目标组质量 | 约 0.176 |
| 最小 prototype 距离 | 源域约 2.30；目标域约 18.33 以上 |
| Collapse | 未观察到 |

当前最合理的解释是：prototype 的跨域几何距离被改善了，但这个改善尚未改变最终组内 OT 与近邻分类的结构。换言之，prototype-level alignment 不是当前下游指标的充分代理。

## ✅ 下一步判断

这条联合优化方向值得保留，但不应立刻扩大种子、调权重网格或加入 ROCA。下一轮只需先检查一个更直接的问题：prototype 更新后，组传输 $P$、组内 transport objective 与样本 coupling 是否发生实质变化；若这些量也几乎不变，则应重新设计 Block B，使其使用样本级 $Q_{kl}$ 信息，而不是继续放大当前 prototype-only cross loss。
