# 软分组首次实验结果解读与下一步计划

## 0. 先给结论

这次 Codex 跑出来的结果不是“软分组失败”，也不是“软分组成功”，而是更精确地说明了一个事实：

> TACO 式原型分组可以产生有结构的自动分组；但是把连续软权重直接塞进 HiWA 的随机初始化流程，会放大 HiWA 的非凸优化问题。硬原型暖启动可以让软权重安全接入，但目前还没有带来方向准确率提升。

所以现在的项目状态应该写成：

```text
Soft-Prototype HiWA 第一版已经跑通。
原型学习有效。
随机软优化不稳定。
暖启动软优化稳定但没有明显增益。
下一步应解决“软权重如何安全释放”的优化机制问题。
```

目前最重要的不是继续疯狂跑更多随机种子，而是先回答：

> 为什么软权重没有转化成性能增益？  
> 它是因为软分组本身没用，还是因为优化器没有正确利用软分组？

从已有图来看，更像第二种：**软分组有结构，但优化机制还没有把边界不确定性用好。**

TACO 式原型学习

## 2. 三张图分别在说明什么

## 2.1 第一张图：温度敏感性

第一张图有两个子图：

```text
Development seeds: direction accuracy
Development seeds: movement score
```

它是在开发种子上比较不同 softmax temperature 的效果。

这里的 temperature 记作：

$$
\tau
$$

soft assignment 大致是：

$$
A_{ki}
=
\frac{
\exp(\langle x_k,c_i\rangle/\tau)
}{
\sum_r\exp(\langle x_k,c_r\rangle/\tau)
}
$$

$\tau$ 控制软分组的“软硬程度”。

### $\tau$ 小

当 $\tau$ 比较小时，softmax 更尖锐。

此时：

$$
A_{ki}
$$

更接近 one-hot。

也就是说，每个样本更像只属于一个组。

这接近硬分组。

### $\tau$ 大

当 $\tau$ 比较大时，softmax 更平滑。

此时一个样本会同时属于多个组。

这会保留更多边界不确定性，但也会造成组与组之间重叠过强。

### 图中的结果

从第一张图看：

- $\tau=1.0$ 时，方向准确率明显下降，movement $R^2$ 甚至变成负值；
- $\tau=0.5$ 时，方向准确率和 movement $R^2$ 最稳定；
- $\tau=0.25$ 时，方向准确率还可以，但 movement $R^2$ 方差很大，说明可能出现灾难性失败。

这里最重要的不是“$\tau=0.5$ 最好”，而是：

> 软度会强烈影响 HiWA 的非凸优化路径。

也就是说，温度不是一个小参数，而是会改变模型落入哪个局部极小值。

## 2.2 第二张图：独立种子比较

第二张图有两个子图：

```text
Held-out seeds: direction
Held-out seeds: movement
```

它比较了三个方法：

```text
prototype hard
soft random init
soft warm start
```

这三个方法的区别如下。

| 方法 | 含义 | 作用 |
|---|---|---|
| prototype hard | 对 soft assignment 取 `argmax`，变成硬分组 | 自动硬分组基线 |
| soft random init | 直接使用连续软权重，从随机旋转开始 | 检验“直接软化”是否有效 |
| soft warm start | 先跑 prototype hard，再用它的 $P,R$ 初始化软版本 | 检验“软化作为细化”是否有效 |

图中黑色菱形表示平均值，误差棒表示波动。灰线表示同一个随机种子在不同方法之间的变化。

### 方向准确率图

方向准确率上：

```text
prototype hard 和 soft warm start 基本一样。
soft random init 平均更低，且波动更大。
```

这说明：

> 直接软化没有提升，反而可能把可用的硬原型结果拉坏。

### movement $R^2$ 图

movement $R^2$ 上：

```text
prototype hard 稳定在较高正值。
soft warm start 也稳定。
soft random init 有一个种子严重掉到负值。
```

$R^2<0$ 的意思是：

> 模型比“只预测平均值”还差。

所以 soft random init 的问题不是普通误差，而是某些种子进入了错误旋转或错误局部解。

### 这张图的核心结论

第二张图最重要的结论是：

> 暖启动能消除灾难性失败，但还没有让软权重带来额外收益。

这意味着软权重不是完全不能用，而是不能从随机状态直接释放。它需要一个稳定的硬结构作为起点。

## 2.3 第三张图：软组结构

第三张图有三个子图：

```text
Neural soft groups
Movement soft groups
Maximum group membership
```

前两个图展示神经空间和运动空间中的 soft groups。颜色表示样本最大归属对应的 prototype，黑色叉号表示 prototype。

第三个图展示每个样本最大归属概率：

$$

$$

这个值越接近 1，说明这个样本越像硬分组；越接近 $1/K$，说明越模糊。

### 你应该怎么看第三张图

第一，神经和运动空间都确实形成了几个可辨认区域。

这说明原型学习不是乱的。

第二，movement soft groups 看起来更像方向扇区。

这说明运动空间的结构更清晰。

第三，Maximum group membership 中大量样本接近 1。

这说明：

> 在 $\tau=0.5$ 下，大多数样本已经非常接近硬分组，真正“软”的主要是边界样本。

这解释了为什么 soft warm start 和 prototype hard 几乎一样：

```text
因为绝大多数样本已经几乎 hard。
软权重只改变少数边界点。
如果优化器没有专门利用这些边界点，就不会产生明显提升。
```

## 3. 几个指标到底是什么意思

## 3.1 Direction accuracy

direction accuracy 是运动方向分类准确率。

如果是四分类，随机猜测水平是：

$$
\frac{1}{4}=0.25
$$

图中虚线 $0.25$ 就是四分类随机水平。

所以准确率 $0.54$ 的意思是：

> 模型明显高于随机猜测，但还没有到非常强的水平。

在你的实验中，prototype hard 和 soft warm start 都在 $0.54$ 左右，说明自动原型分组已经有一定方向语义。

## 3.2 Movement score / $R^2$

movement score 用的是 $R^2$。

直观上：

- $R^2=1$ 表示预测非常好；
- $R^2=0$ 表示和预测均值差不多；
- $R^2<0$ 表示比预测均值还差。

所以第一张图中 $\tau=1.0$ 或第二张图中 soft random init 的负 $R^2$ 都是危险信号。

它说明模型不是稍微差一点，而是对连续运动结构对齐失败。

## 3.3 Error bar

误差棒表示不同随机种子之间的波动。

误差棒越大，说明方法越不稳定。

soft random init 的误差棒很大，说明它强烈依赖初始化。

## 3.4 Development seeds 和 held-out seeds

development seeds 是开发种子，用来选参数。

held-out seeds 是未参与调参的新种子，用来确认结果。

因此 held-out seeds 更可信。

不能拿 development seeds 中某个好结果直接宣称方法成功，因为那可能是调参选择偏差。

## 4. 这次结果到底说明了什么

## 4.1 能说明的事情

这次实验可以说明：

1. **TACO 式原型学习值得保留。**  
   它能在不使用真实方向标签的情况下，学出有结构的四组表示。

2. **软权重可以接入 HiWA。**  
   加权 Sinkhorn 的边缘约束正确，说明数学实现不是乱的。

3. **随机软优化不稳定。**  
   从随机旋转同时解决软分组、组对应、局部传输和全局旋转，容易进入坏局部解。

4. **硬解暖启动是有效稳定器。**  
   先用 prototype hard 找到可用的 $P,R$，再释放软权重，可以避免灾难性失败。

5. **当前软权重还没有带来性能增益。**  
   暖启动稳定，但方向准确率没有超过硬原型。

## 4.2 不能说明的事情

这次实验不能说明：

1. 不能说明所有软分组都无效；
2. 不能说明 TACO 方法无效；
3. 不能说明软权重永远不能提升 HiWA；
4. 不能说明硬原型已经是最优；
5. 不能说明 $R^2$ 的微小提升有意义；
6. 不能说明方法已经可以写成最终正结果。

更准确的说法是：

> 当前版本证明了可行性和风险，但还没有证明性能收益。

## 5. 为什么随机软分组会失败

原始 HiWA 的硬簇有一个特点：

```text
一个样本只属于一个簇。
```

所以每个样本只在一个组对中参与局部对齐。

但是 soft group 中，一个样本可能同时进入多个组。

这会导致：

```text
同一个样本参与多个局部旋转估计
→ 不同组对给出冲突的旋转证据
→ 全局旋转共识被多个局部解拉扯
→ 随机初值决定掉进哪个局部极小值
→ 某些种子出现方向下降或 R² 为负
```

也就是说，软组的优势是：

> 边界样本可以表达不确定性。

但它的风险是：

> 边界样本会重复参与多个局部对齐，从而放大非凸冲突。

所以软分组不是自动变好，它必须配合更稳的优化策略。

## 6. 为什么暖启动有用但没有提升

暖启动流程是：

```text
先跑 prototype hard
→ 得到一个可用的 P 和 R
→ 再用这个 P,R 初始化 soft version
→ 让软权重只做局部细化
```

它有用，是因为它避免了从随机状态同时解决三个困难问题：

1. 组对应；
2. 局部样本传输；
3. 全局旋转。

但是它没有提升，原因可能是：

1. $\tau=0.5$ 时多数样本已经接近 hard assignment；
2. 只有少量边界样本真正是软的；
3. 当前全局旋转更新没有特别重视“哪些组对可信”；
4. 软权重只是被动加入，没有反向影响 prototype；
5. 稀疏保留 $90\%$ 质量可能削弱了边界样本的作用；
6. 当前优化器更像是在硬解附近做微调，而不是重新利用软不确定性。

所以暖启动解决的是：

```text
稳定性问题
```

但还没有解决：

```text
性能增益问题
```

## 8. 下一步应该做什么

下一步应该围绕一个核心问题：

> 如何在不破坏硬原型好解的条件下，让软边界样本真正发挥作用？

我建议按优先级做下面四件事。

---

## 8.1 第一优先级：做温度退火

当前固定 $\tau=0.5$ 的问题是：

```text
一开始就释放软重叠
→ 随机初始化容易被冲突组对拉坏
```

温度退火的思想是：

```text
先接近硬分组
→ 找到稳定组对应和旋转
→ 再逐渐变软
→ 让边界不确定性慢慢进入优化
```

可以设置：

$$
\tau_0<\tau_1<\cdots<\tau_T
$$

例如：

$$
0.25\rightarrow0.35\rightarrow0.50
$$

或者：

$$
0.20\rightarrow0.30\rightarrow0.40\rightarrow0.50
$$

每一步用前一步的 $P,R$ 做 warm start。

这样不是直接从随机状态跑 $\tau=0.5$，而是让模型先学到稳定结构，再释放软度。

### 退火实验怎么比较

至少比较三组：

| 方法 | 说明 |
|---|---|
| Prototype hard | 原型硬化基线 |
| Fixed soft warm start | 固定 $\tau=0.5$ 的暖启动 |
| Annealed soft | 从低温逐步升到 $\tau=0.5$ |

如果 Annealed soft 在方向准确率或 $R^2$ 上超过前两者，才说明软度释放机制有效。

---

## 8.2 第二优先级：做 $P_{ij}$ 加权全局旋转共识

当前问题之一是：

> 低可信组对和高可信组对可能对全局旋转产生同等影响。

但是 group-level transport matrix $P$ 本来就表示组对的可信程度。

如果：

$$
P_{ij}
$$

很大，说明第 $i$ 个源组和第 $j$ 个目标组更可能对应。

如果：

$$
P_{ij}
$$

很小，说明这个组对不可信。

所以更新全局旋转 $R_g$ 时，可以考虑按 $P_{ij}$ 加权：

$$
R_g
=
\operatorname{Proj}_{\mathcal O(d)}
\left(
\sum_{i,j}P_{ij}(R_{ij}+L_{ij})
\right)
$$

这里：

- $R_{ij}$ 是局部旋转；
- $L_{ij}$ 是 ADMM 乘子项；
- $\operatorname{Proj}_{\mathcal O(d)}$ 表示投影到正交矩阵集合；
- $P_{ij}$ 控制这个组对对全局旋转的影响。

这一步的直觉是：

> 可信组对多说话，不可信组对少说话。

这很适合 soft group，因为 soft group 会产生更多重叠和弱组对。

### 这个实验必须单独消融

你不能同时加入退火和 $P$ 加权，然后说变好了。

应该分开做：

| 方法 | 是否退火 | 是否 $P$ 加权共识 |
|---|---|---|
| Soft warm start | 否 | 否 |
| Annealed soft | 是 | 否 |
| P-weighted soft | 否 | 是 |
| Annealed + P-weighted | 是 | 是 |

这样才能知道提升来自哪里。

---

## 8.3 第三优先级：只对边界样本使用软权重

第三张图显示，大多数样本最大归属概率接近 1。

这说明大部分样本其实已经是硬样本。

真正需要 soft assignment 的是边界样本。

所以可以考虑一个 hybrid 策略：

```text
高置信样本用 hard assignment
低置信边界样本用 soft assignment
```

定义最大归属概率：

$$
s_i=\max_k A_{ik}
$$

如果：

$$
s_i>\rho
$$

就把样本硬化。

如果：

$$
s_i\leq \rho
$$

保留软权重。

例如：

$$
\rho=0.9
$$

这样做的好处是：

1. 减少大多数非边界样本的重复参与；
2. 保留真正边界样本的不确定性；
3. 降低软组重叠造成的局部旋转冲突。

这可能比全体样本都软更适合当前 HiWA 优化器。

---

## 8.4 第四优先级：检查经验组级边缘

当前组级 $P$ 可能使用均匀边缘。

但如果 soft groups 的实际质量不均衡，均匀边缘可能强迫每个 group 同等重要。

可以比较：

### 均匀组级边缘

$$
\alpha_i=\frac{1}{K_X}
$$

$$
\beta_j=\frac{1}{K_Y}
$$

### 经验组级边缘

$$
\alpha_i=\frac{1}{n}\sum_k A_{ki}
$$

$$
\beta_j=\frac{1}{m}\sum_l B_{lj}
$$

如果某些 group 实际上很小，经验边缘能避免它们被强行赋予过大质量。

这一步不是第一优先级，但值得作为消融实验。

## 11. 现在项目应该怎么表述

你现在可以这样描述当前进展：

> 我们实现了 Soft-Prototype HiWA 的第一版，将 HiWA 的硬簇替换为由 TACO 式原型学习诱导的软组条件分布。首次实验表明，原型学习能够在无方向标签参与训练的情况下形成结构清楚的自动分组；但连续软权重直接接入随机初始化的 HiWA 会导致优化不稳定，出现坏局部解。硬原型暖启动可以稳定接入软权重，但尚未带来方向准确率提升。因此下一步重点不是扩大种子数量，而是设计更合理的软权重释放机制，例如温度退火和按组对应置信度加权的全局旋转共识。

这句话非常重要，因为它把当前结果讲得既不夸大，也不沮丧。

---

## 12. 最后的判断

这次结果其实是好的。

不是因为它已经提升了准确率，而是因为它把问题变清楚了。

原来你的问题是：

```text
TACO 的软分组能不能用到 HiWA？
```

现在问题变成了：

```text
TACO 式原型学习能产生有效自动组；
但 soft weights 会放大 HiWA 的非凸优化问题；
我们需要温度退火或置信度加权，让软边界样本在稳定结构上发挥作用。
```

这就是一个真正的研究问题。

一句话总结：

> 当前 Soft-Prototype HiWA 的瓶颈不是“软分组没有结构”，而是“软分组的重叠信息没有被 HiWA 优化器稳定利用”。下一步应该先做温度退火，再检查 $P_{ij}$ 加权旋转共识，而不是马上扩大种子或加入标签损失。
