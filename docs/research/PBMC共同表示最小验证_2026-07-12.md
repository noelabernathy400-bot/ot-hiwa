# PBMC 共同表示最小验证

_日期：2026-07-12；数据：本地 10x Multiome PBMC RNA–ATAC 文件；状态：完成，停止扩大当前 PBMC 实验。_

---

## 🎯 目的

验证把 RNA 表达与 ATAC gene activity 投入同一组基因特征、共同 PCA 与共同缩放后，是否能为当前 Hard HiWA 与 fixed-assignment Soft-GCOT HiWA 提供非随机的配对检索信号。

构造过程没有使用 cell ID 或 `cell_type`。二者只在最终评价时使用。

## 🧬 表示构造

| 项目 | 设置 |
| --- | --- |
| 细胞 | 96 个确定性共同细胞，seed 120 |
| 共享基因轴 | 2,000 个 RNA 高变基因 |
| ATAC gene activity | 每个 peak 与同染色体上 gene body ±2 kb 的区间重叠后聚合 |
| peak–gene 边 | 13,793 条 |
| 降维 | 在拼接后的 RNA 与 ATAC 矩阵上共同拟合 20 维 PCA |
| 缩放 | 在拼接后的 PCA 坐标上共同拟合一个 `StandardScaler` |
| 分组与对齐 | 同 prototype 的 Hard HiWA 与 full-support Fixed Soft-GCOT；4 组；既有温度路径与 Hard warm start |

共同缩放是必要条件：若分别对两个模态重新拟合缩放器，即使 PCA 基底相同，两个坐标系仍会被各自的均值与尺度重新改变。

## 📊 结果

随机配对检索基线为 `R@1 = 1/96 = 0.0104`、`R@5 = 5/96 = 0.0521`。

| 方法 | 形式收敛 | 迭代 | R@1 | R@5 | cell-type transfer | 运行时间 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 同 prototype Hard HiWA | 是 | 63 | 0.0000 | 0.0313 | 0.0729 | 7.31 s |
| Full-support Fixed Soft-GCOT | 是 | 54 | 0.0208 | 0.0417 | 0.0729 | 19.47 s |

Soft-GCOT 的 `R@1 = 2/96` 高于随机期望，但 `R@5` 仍低于随机基线，且 cell-type transfer 没有改善。因此，这一个 smoke test 没有形成稳定、可解释的跨模态对齐信号。

## ✅ 决定

当前 PBMC 分支在这里停止，不运行更多 seed、不调温度、不加入 ROCA，也不以该结果评价 Soft-GCOT 的优劣。

这次验证支持的结论是：共享 gene-activity 特征空间可以无标签构造，但它尚未让 RNA–ATAC 的几何关系接近当前 HiWA 所假设的正交可对齐关系。PBMC 不适合作为当前模型的第二主验证数据。

## ➡️ 下一步

保留已冻结的 MiHiA 基线与两种联合优化负结果。下一项数据工作应优先寻找与 MiHiA 更接近的同模态跨 session／跨主体神经数据，而不是继续在 PBMC 上调整当前模型。
