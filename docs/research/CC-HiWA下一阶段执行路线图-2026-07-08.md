# CC-HiWA 下一阶段执行路线图

## 1. 当前阶段已经覆盖的研究骨干

截至 2026-07-08，研究骨干已经从局部 ROCA 问题扩展为：

> TACO-inspired Component-Conditioned HiWA for general multimodal alignment.

已落地内容：

1. 明确 CC-HiWA 是主方法；
2. 明确 ROCA 是 3D 神经—运动场景的稳定化模块；
3. 明确 RGCA 是浅层 representative guidance 探索，不进入当前主方法；
4. 明确 TACO 的核心迁移点不是软聚类，而是 group-conditioned sample transport；
5. 明确至少三个不同领域数据集：
   - 神经—运动；
   - RNA–ATAC；
   - 图像—文本；
6. 已实现数据集无关的 `cc_hiwa.py` 核心接口；
7. 已新增 CC-HiWA 单元测试；
8. 全部 unittest 已通过。

## 2. 当前主方法定义

CC-HiWA 的核心公式：

$$
r_k^X=
\frac{\sum_i a_{ik}^Xx_i}{\sum_i a_{ik}^X}
$$

$$
r_l^Y=
\frac{\sum_j a_{jl}^Yy_j}{\sum_j a_{jl}^Y}
$$

$$
P=\operatorname{Sinkhorn}(C^{group})
$$

$$
S=A P B^\top
$$

$$
C_{ij}^{CC}
=
C_{ij}^{base}
-
\beta\log(S_{ij}+\epsilon)
$$

$$
T=\operatorname{Sinkhorn}(C^{CC})
$$

这就是从 TACO / GCOT 迁移来的核心：样本级 OT 由组件级对应关系条件化。

## 3. 下一步不要做什么

暂时不要：

- 继续扩大 RGCA 调参；
- 继续追 ROCA 的临时最高 accuracy；
- 直接新增复杂神经网络 encoder；
- 在没有统一接口前同时下载三个大数据集；
- 用测试标签选择 $\beta$；
- 把 ROCA 强行写成所有数据集都需要的模块。

## 4. 下一步应该做什么

### Step 1：在当前神经—运动数据上接入 CC-HiWA

目标：

> 用当前已跑通的 D1 数据验证 `cc_hiwa.py` 可以接入真实任务。

最小实验：

- 输入：已有 neural_3d, movement_3d；
- assignments：复用当前 soft group assignments；
- 方法：`fit_cc_hiwa`；
- $\beta$：0, 0.1, 0.25, 0.5；
- evaluation：direction accuracy, movement $R^2$；
- 对照：ROCA-HiWA / Soft-HiWA。

注意：

- 第一版可不更新 Procrustes rotation；
- 先验证 component-conditioned sample transport 是否改变 nearest-neighbor 结构；
- 不追求一次超过 ROCA。

### Step 2：准备 PBMC RNA–ATAC 数据适配器

目标：

> 把单细胞数据转成统一接口 $X,Y,A,B,\mathcal{E}$。

第一版建议：

- 使用公开 PBMC multiome；
- RNA embedding 和 ATAC embedding 可先用 PCA/LSI；
- assignments 可用 KMeans/GMM/soft prototypes；
- labels 只用于最终 cell type transfer。

输出文件：

- `scripts/prepare_pbmc_multiome.py`
- `results/datasets/pbmc_multiome_summary.json`

### Step 3：准备图像—文本 embedding 数据适配器

目标：

> 用小型图文 embedding 验证 CC-HiWA 不是生物/神经专用。

第一版建议：

- 不训练 CLIP；
- 使用预训练 image/text embeddings；
- 选择 Flickr8k/Flickr30k/COCO subset；
- assignments 用 embedding 上的 soft prototypes；
- evaluation 用 Recall@K。

输出文件：

- `scripts/prepare_image_text_embeddings.py`
- `results/datasets/image_text_summary.json`

### Step 4：统一实验 runner

目标：

> 一个 runner 跑所有已适配数据集。

接口草案：

```bash
python scripts/run_cc_hiwa_dataset.py --dataset neural_movement --beta 0 0.1 0.25 0.5 --tag ...
```

```bash
python scripts/run_cc_hiwa_dataset.py --dataset pbmc_multiome --beta 0 0.1 0.25 0.5 --tag ...
```

```bash
python scripts/run_cc_hiwa_dataset.py --dataset image_text --beta 0 0.1 0.25 0.5 --tag ...
```

统一输出：

- raw JSON；
- summary JSON；
- figures；
- method comparison table；
- failure cases。

## 5. 三阶段论文路线

### 阶段 A：方法骨干

写清楚：

- TACO 到 CC-HiWA 的迁移；
- group-conditioned sample OT；
- ROCA 的辅助地位；
- 三数据集统一接口。

### 阶段 B：一个数据集跑通

先在当前神经—运动数据上跑通：

- CC-HiWA 是否能运行；
- 是否改变 transport；
- 是否改善或至少保持 direction / $R^2$；
- 是否能和 ROCA 共存。

### 阶段 C：跨领域验证

再接 PBMC 和图文：

- 如果三个都有效：主张通用方法；
- 如果两个有效一个失败：写成适用边界；
- 如果只有神经有效：退回神经专用论文，不再声称 general method。

## 6. 成功标准

最低成功：

- 三个数据集都能转成统一接口；
- CC-HiWA 能跑通；
- 至少两个数据集优于 direct OT / soft baseline；
- 标签不进入训练或选择；
- 失败案例有记录。

强成功：

- 三个数据集均有稳定提升；
- $\beta$ 不需要每个数据集极端调参；
- component compatibility $S$ 能解释匹配结构；
- ROCA 在 D1 中增强稳定性，但不是主方法必要条件。
