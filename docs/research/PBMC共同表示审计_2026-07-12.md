# PBMC 共同表示审计

_2026-07-12 · 10x Multiome PBMC RNA–ATAC 输入适配_

---

## 发现

| 项目 | RNA | ATAC |
| --- | --- | --- |
| 维度 | 9,631 × 29,095 | 9,631 × 107,194 |
| 预计算 embedding | 无 `obsm` | 无 `obsm` |
| 可用坐标 | 基因的 `chrom/chromStart/chromEnd` | peak 的 `chrom/chromStart/chromEnd` |
| 细胞注释 | `cell_type` | `cell_type` |

两个文件共享相同的 cell IDs，但这些 ID 只用于最终配对检索评价。现有文件不包含 `X_pca`、`X_lsi`、`X_glue` 或 gene activity，因此旧的独立 RNA-SVD/ATAC-SVD 并不是共同坐标系。

## 决定

下一步采用无标签 gene-activity 构造：以 RNA 基因坐标与 ATAC peak 坐标在同一染色体上的 gene body 加减 2 kb 区间重叠为关联，聚合 peak accessibility 到基因层面。之后 RNA 与 ATAC 使用相同基因集合、相同无监督归一化和降维，再测试 Hard HiWA 与 full-support Fixed Soft-GCOT。

坐标覆盖检查显示常染色体与 X 染色体均有大量可关联 peaks，例如 chr1 为 7,661/10,473 个 peaks。因此该共同表示在当前文件中可构造；未使用 cell ID 或 cell type 进行构造。

## 后续最小验证

先生成共同基因空间，只运行 96 个确定性细胞与 seed 120。若检索显著高于随机基线 \(R@1=1/96\)、\(R@5=5/96\) 且两种方法收敛，再扩展到三个 seed；否则停止 PBMC 作为当前 HiWA 的验证数据。
