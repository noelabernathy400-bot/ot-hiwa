# 联合优化机制诊断与 PBMC 最小基线

_2026-07-12 · 记录固定 MiHiA 子集的联合优化诊断，以及配对 PBMC RNA–ATAC 的首次最小运行_

---

## 结果概览

本次完成两项工作：

1. 为交替 Joint Soft-GCOT 保存每轮的 (S,T,P,R,Q,\Pi) 变化摘要
2. 恢复本地 PBMC Multiome 数据，建立同-prototype Hard HiWA 与 full-support fixed Soft-GCOT 的配对细胞最小 runner

两项结果都不支持立即修改联合目标或扩展 PBMC 规模。联合优化诊断说明 prototype 更新后，样本级对齐只发生很小改变；PBMC 的 96-cell 首轮只有 2/3 个 seed 按收敛规则完成，且检索结果没有稳定方向。

## 联合优化机制诊断

使用冻结的 MiHiA \(96\times96\) 子集、seeds 100–102、3 个联合外循环。每个循环保存最后一阶段的软分配 \(S,T\)、组传输 \(P\)、全局旋转 \(R\)、局部 couplings \(Q_{kl}\) 与全局样本 coupling \(\Pi=\sum_{kl}P_{kl}Q_{kl}\) 的差异摘要。

| 变化 | 外循环 0 → 1 | 外循环 1 → 2 | 解释 |
| --- | ---: | ---: | --- |
| 源软分配 Frobenius 范数 | 0.528–0.547 | 0.00535–0.00581 | 第一次 prototype 更新有移动，第二次已基本稳定 |
| 源分配 argmax 改变比例 | 1/96 | 0/96 | 硬组身份几乎不变 |
| \(\|P^{t+1}-P^t\|_F\) | \(7.8\times10^{-5}\)–\(2.3\times10^{-4}\) | \(9.7\times10^{-6}\)–\(2.3\times10^{-5}\) | 组级对应几乎不变 |
| \(\|R^{t+1}-R^t\|_F\) | 0.021–0.054 | 0.00039–0.00250 | 旋转变化很小且迅速稳定 |
| \(\|\Pi^{t+1}-\Pi^t\|_F\) | 0.00214–0.00261 | \(5.9\times10^{-5}\)–\(7.1\times10^{-5}\) | 全局样本传输只发生轻微重分配 |
| 局部 \(Q_{kl}\) 差异均值 | 0.00277–0.00298 | \(8.0\times10^{-5}\)–\(9.1\times10^{-5}\) | 局部 OT 同样迅速稳定 |

因此，prototype-distance 联合项确实改变了连续 soft assignment，却只改变了约一个样本的硬组归属，且 \(P,Q,R,\Pi\) 的后续变化均很小。这与此前 Joint Soft-GCOT 的方向准确率没有变化相一致。

> 当前证据支持“prototype-only cross loss 对样本级 OT 的影响过弱”，但尚不足以直接实现新的 transport-consistent assignment loss。下一版若推进，应以 \(P\) 和 \(Q\) 直接约束软分配为清楚的单独方法变更。

诊断数据：`experiments/results/alternating_joint_soft_gcot_joint_soft_gcot_mechanism_100_102.json`。

## PBMC 最小基线

原始配对 RNA/ATAC `.h5ad` 文件从旧工作目录恢复到 `data/pbmc/raw/`；它们和产生的处理后 `.npz` 均被 `.gitignore` 排除。预处理得到 1,000 个配对细胞、20 维 RNA/ATAC embedding、4 个候选组和可选 cell-type 标签。

为了符合当前 NumPy full-support 的计算边界，runner 从这 1,000 个配对细胞中确定性等距选取 96 个细胞。Hard labels 取自同一套最终 soft assignments 的 `argmax`；Soft 使用相同 prototype、温度路径 \(0.25\rightarrow0.35\rightarrow0.50\)、Hard warm start 与 full support。cell ID 配对和 cell type 仅用于最终评价。

| Seed | Hard 收敛 | Soft 收敛 | Hard R@1 | Soft R@1 | Hard R@5 | Soft R@5 |
| ---: | --- | --- | ---: | ---: | ---: | ---: |
| 100 | 是 | 是 | 0.0000 | 0.0208 | 0.0208 | 0.0625 |
| 101 | 否 | 否 | 0.0000 | 0.0000 | 0.0625 | 0.0208 |
| 102 | 是 | 是 | 0.0208 | 0.0104 | 0.0312 | 0.0312 |

这只是管线可运行性的初始证据，不是 Soft 优于 Hard 的结论。它表明当前 MiHiA 的数值协议不能未经适配直接迁移到 PBMC：在 3 个 seed 中只有 2 个满足收敛判据，且两个收敛 seed 的 R@1 变化方向相反。

PBMC 结果：`experiments/results/soft_gcot_pbmc_pbmc_paired_96_seeds_100_102.json`。

## 下一步

1. 冻结此次结果，不再扩大相同 PBMC 设置的 seed 数
2. 保留现有 prototype-only 联合版本作为已诊断的对照，不继续扫描 `lambda_cross`
3. 在开始 transport-consistent assignment 目标前，先明确 PBMC 需要的独立数值适配方案；它不能与 MiHiA 的性能结论混合
4. 若继续联合优化，下一项方法变更应直接使用 \(P\) 与 \(Q\) 约束配对样本的 group membership，而非仅拉近 prototypes
