# GC-HiWA v3：截断 DP 软群组的数学合同与准入实验

## 决策

将“自动确定群组数”作为一个独立的 v3 研究分支，而不是替换已验证的固定四群组主干。

推荐采用截断 Dirichlet Process（DP）式软群组，而不采用训练中动态 split/merge。原因是截断 DP 保持维度上界固定、成员关系连续可微，并能保留 Soft-GCOT 所需的软隶属度；split/merge 会在 ADMM 迭代中突然改变群组状态和外层 OT 矩阵维度，难以区分数值震荡与真实结构变化。

本文件是实现前的合同。没有通过第 7 节准入实验前，v3 不得替代 v2 的任何主结果。

## 1. 要解决的问题

固定 \(K=4\) 在当前合成四面体与三维 ROCA 设计中合理，但不是所有姿态分布都天然有四个群组。v3 的目标不是追求更多簇或更低训练成本，而是：

\[
\text{当数据确有更少或更多可辨群组时，自动选择有效群组数；}
\]

\[
\text{当群组数不稳定或跨域结构不兼容时，明确弃权。}
\]

## 2. 截断 DP 式、旋转等变软群组

对每个域 \(D\in\{X,Y\}\)，预设计算上限 \(S_{\max}\)，初始建议为 8。令
\(\pi^D=(\pi^D_1,\ldots,\pi^D_{S_{\max}})\) 为非负混合权重，满足
\(\sum_k\pi^D_k=1\)。可用截断 stick-breaking 参数化：

\[
v^D_k\sim\operatorname{Beta}(1,\alpha),\qquad
\pi^D_k=v^D_k\prod_{\ell<k}(1-v^D_\ell).
\]

在整体标量标准化后的坐标中，以各向同性距离定义软隶属度：

\[
A^D_{ik}=
\frac{\pi^D_k\exp\left(-\lVert z^D_i-c^D_k\rVert_2^2/\tau\right)}
{\sum_{\ell=1}^{S_{\max}}\pi^D_\ell
\exp\left(-\lVert z^D_i-c^D_\ell\rVert_2^2/\tau\right)}.
\]

有效质量为

\[
m^D_k=\frac{1}{n_D}\sum_{i=1}^{n_D}A^D_{ik}.
\]

若 \(z^Y_i=z^X_iR^\top\)，\(R\in O(d)\)，并同时令
\(c^Y_k=c^X_kR^\top\)，则各向同性距离及 \(A_{ik}\) 不变。因此，该定义与 v2 的整体标量标准化共同保持未知正交坐标变换的等变性。不得使用逐坐标方差、轴对齐协方差或 per-feature z-score。

## 3. 群组数不是独立删掉的

标准 DP-GMM 若在两个域独立剪枝，可能得到不同的有效群组数。这并非自动成功：

- 目前的相对拟合比以一一 Hungarian 群组匹配计算；群组数不同会使它失去定义；
- 当前 ROCA 在三维中要求恰好四个原型组成定向单纯形；
- 单域中的小群组可能是噪声，也可能是另一域的重要姿态模式。

因此，v3 不允许“分别训练两个 DP-GMM 后直接送入 GC-HiWA”。有效群组必须通过跨域 OT 共同解释。

## 4. 非均匀群组 OT 合同

外层传输不再使用均匀边际，而使用经下界截断和重归一化后的有效质量：

\[
\bar m^D_k=
\frac{\max(m^D_k,m_{\min})}
{\sum_{\ell=1}^{S_{\max}}\max(m^D_\ell,m_{\min})}.
\]

群组 OT 约束变为

\[
P\mathbf1=\bar m^X,\qquad P^\top\mathbf1=\bar m^Y,\qquad P\ge0.
\]

这样 \(P\) 可以是 \(S_{\max}\times S_{\max}\)，而低质量群组获得近零传输质量。迭代期间矩阵维度不变；只有训练完成后、且在全部重启中稳定低于 \(m_{\min}\) 的群组才可从报告中标记为非活跃。

不再使用只在相等群组数下定义的 Hungarian 相对拟合比。替代指标是传输加权的全局交叉成本：

\[
L_{\mathrm{cross}}=\sum_{k,\ell}P_{k\ell}C^{(g)}_{k\ell},
\]

\[
L_{\mathrm{self}}=
\tfrac12\left(
\sum_k\bar m^X_kC^{X,\mathrm{self}}_k+
\sum_\ell\bar m^Y_\ell C^{Y,\mathrm{self}}_\ell
\right),
\qquad
\eta_{\mathrm{mass}}=\frac{L_{\mathrm{cross}}}{L_{\mathrm{self}}}.
\]

这一定义允许多个细群组映射到一个粗群组，但它改变了 v2 的资格门槛，必须重新标定；不得复用 \(\eta\le1.5\) 的数值。

## 5. 稀疏化与跨域一致性

DP 先验或 log-sum 稀疏项只用于鼓励不必要群组的权重变小，例如

\[
\mathcal L_{\mathrm{stick}}
=-\lambda_{\mathrm{DP}}\sum_{D\in\{X,Y\}}\sum_k\log\pi^D_k.
\]

它不能单独决定删群。另加跨域质量一致性项：

\[
\mathcal L_{\mathrm{mass}}
=\lambda_{\mathrm{mass}}\sum_{k,\ell}P_{k\ell}
\left(\log(\bar m^X_k+\epsilon)-\log(\bar m^Y_\ell+\epsilon)\right)^2.
\]

这不是强迫两个域拥有相同编号的原型，而是通过实际传输 \(P\) 惩罚无法解释的质量失配。若该项、\(\eta_{\mathrm{mass}}\) 或多启动稳定性失败，系统应弃权。

## 6. ROCA 的明确边界

当前 ROCA 在三维使用四个群组代表元的定向四面体。因此：

1. 当稳定有效群组数恰好为四时，可复用当前 ROCA；
2. 当有效群组数不是四时，v3 的 ROCA 默认**不选择反射分支**，而是弃权；
3. Panoptic 相机坐标主应用预先知道物理变换属于 \(SO(3)\)，可固定 \(\det(R)=+1\)，因而不需要 ROCA；
4. 未来若要对任意 \(K\) 支持 ROCA，必须另行证明或验证一个稳定的最大体积四面体选择规则；它不能在本版本中被假定成立。

这一限制不是缺陷掩盖，而是防止“自动簇数”绕开现有分支选择的可识别条件。

## 7. 准入实验：先证明值得加入

### 7.1 不可退化测试

沿用现有四群组、正交、噪声和失配合成协议。v3 至少应满足：

1. 有效群组数稳定为四；
2. 旋转误差、接受／弃权决策不劣于固定 \(K=4\)；
3. 不增加错误接受；
4. 固定四群组结果无需重调 v2 超参数。

若此项失败，停止 v3，不进入真实数据。

### 7.2 真正需要自动群组数的测试

新增冻结合成生成器，真实群组数 \(K_\star\in\{2,3,5,6\}\)，每种条件包含：

- 单一正交变换；
- 噪声；
- 合并群组或不均衡群组质量；
- 混合旋转；
- 非正交缩放；
- 独立跨模态目标。

评价必须同时报告：

| 指标 | 目的 |
|---|---|
| 稳定有效群组数 | 检查自动选择，而非仅训练损失 |
| 旋转误差与隐藏配对 Recall | 检查几何恢复 |
| 接受、正确弃权、错误接受、错误弃权 | 检查适用性诊断 |
| 相对固定 \(K=4\) 的配对差异 | 检查自动群组是否真正带来价值 |

开发种子与确认种子必须分开。\(S_{\max}\)、\(\alpha\)、\(m_{\min}\)、\(\lambda_{\mathrm{DP}}\)、\(\lambda_{\mathrm{mass}}\) 只能在开发种子固定一次；确认集禁止回调。

### 7.3 真实数据准入

只有第 7.1 与 7.2 都通过，才可将 v3 作为 Panoptic 的探索性分支。真实跨设备语义动作数据仍按照既有冻结协议评价；不能因为 v3 自动选择了某个群组数而使用目标标签或配对挑选它。

## 8. 当前结论

### 8.1 已完成的价值门槛结果

在固定正交、无配对的三维合成数据上，先以种子 2101–2103 比较固定 \(K=4\) 与只供评价的正确 \(K_\star\in\{2,3,4,5,6\}\)。初始三种子中，\(K_\star=5\) 出现“正确 \(K\) 为 3/3 接受、固定 \(K=4\) 为 1/3 接受”的表面差距。

该差距没有通过独立确认：在不重叠的种子 2104–2108、同一五群组合同下，固定 \(K=4\) 为 5/5 接受、平均旋转误差 0.0109；正确 \(K=5\) 为 4/5 接受、平均旋转误差 0.5429，其中一例发生优化失败。因此，现有证据**不支持**“自动群组数能稳定优于固定四群组”的主张。

两群组条件还发现一个不同的问题：两中心近似只确定一个空间方向，绕该方向的旋转不唯一。该条件下协方差最小特征值间隔约为 0.003，而当前固定四群组合成基准约为 0.15–0.38，Panoptic 的物理三维聚合值约为 0.133。旧资格门槛曾错误接受旋转误差很大的两群组解；这属于可识别性不足，不是 DP 应当解决的问题。

### 8.2 当前决策

DP 式自动群组选择暂不实现。正确的下一步是为低几何可识别性情形增加保守弃权诊断，再将固定四群组作为主干保留。只有未来在独立、预先冻结的未知群组数数据上出现稳定的固定 \(K=4\) 缺口，才重新开启本文件第 2–7 节的 DP v3 分支。
