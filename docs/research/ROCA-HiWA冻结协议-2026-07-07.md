# ROCA-HiWA 冻结协议 2026-07-07

## 1. 方法名称

正式名称：Representative-Oriented Component-Aware Soft-HiWA。

简称：ROCA-HiWA。

中文暂译：代表点定向的分支感知 Soft-HiWA。

## 2. 方法目的

ROCA-HiWA 的目的不是继续追逐临时最高 direction accuracy，而是在不使用方向标签的条件下，解决 HiWA / Soft-HiWA 中 $O(3)$ 正交分支选择不稳定问题。

当前研究主线是：

> 借鉴 TACO 式 soft prototype / soft assignment / group-conditioned OT 思想，用 soft cluster representatives 提供跨域有向几何结构，从而无标签选择 HiWA / Soft-HiWA 的正交分支。

## 3. 冻结组件

当前版本冻结如下组件。除非后续协议明确解冻，否则不再根据短期结果反复修改。

| 组件 | 冻结设定 |
|---|---|
| 方法名称 | Representative-Oriented Component-Aware Soft-HiWA，ROCA-HiWA |
| soft prototype 学习 | 沿用当前 `learn_soft_groups` 实现 |
| soft assignment | 对固定 prototypes 按温度生成 soft assignments |
| 组数 | $K=4$ |
| neural representation | 三维 neural representation |
| movement representation | 三维 movement representation |
| 候选分支 | 同时构造 $\det(R)=+1$ 与 $\det(R)=-1$ |
| Procrustes 更新 | determinant-constrained Procrustes |
| representatives | 由 soft assignments 加权平均得到 |
| group matching | 使用两个 determinant 候选的 group transport matrix $P$ 的平均矩阵做 Hungarian matching |
| 分支选择 | 使用 matched representatives 的有向四面体体积符号 |
| 评价协议 | 分支选择后才计算 direction accuracy 和 $R^2$ |
| 标签使用 | 标签只用于最终评价，不进入训练、不进入分支选择 |
| seeds 分区 | 开发与确认 seeds 分离；已有确认 seeds 50--69 与坐标翻转 seeds 70--79 不再用于调公式 |

## 4. 当前不再改的内容

当前阶段暂停以下探索，不把它们混入主结果：

- 不再调 temperature；
- 不再调 entropy weight；
- 不改 $K$；
- 不换聚类方式；
- 不加标签损失；
- 不用测试 accuracy 选择分支；
- 不用测试 $R^2$ 选择分支；
- 不根据结果反复改有向体积选择公式；
- 不继续扩大真实数据随机种子来追分；
- 不加入端到端神经网络训练。

这些方向不是永远不能做，而是放入“后续探索建议”，等当前证据链完成后再设计干净消融。

## 5. 成功标准

ROCA-HiWA 当前版本需要满足：

1. 选择器不使用方向标签；
2. 选择器不使用测试 accuracy；
3. 选择器不使用测试 $R^2$；
4. 在真实数据 seeds 50--69 上稳定选择高 accuracy 分支；
5. 在坐标单轴符号翻转测试中能随手性变化自动改变 determinant 分支；
6. 在合成真值实验中能恢复已知 $\det(R)=+1$ 和 $\det(R)=-1$；
7. representatives 不出现硬退化；
8. 没有 $R^2$ 灾难性失败；
9. direction accuracy 不低于合理自动基线；
10. 失败案例必须保留并解释。

## 6. 失败标准

以下任一情况出现时，不能把 ROCA-HiWA 写成稳定成功：

1. 有向体积接近 0，导致代表点四面体退化；
2. Hungarian matching 对微小扰动极端不稳定；
3. 合成数据中无法恢复真实 determinant；
4. 坐标翻转后仍机械固定选择某个 determinant；
5. 必须使用方向标签才能选对分支；
6. 必须使用测试 accuracy 或测试 $R^2$ 才能选对分支；
7. 大量 seed 低于合理 accuracy 基线；
8. 真实数据成功但合成真值验证失败；
9. 失败案例被隐藏或只报告最好结果。

## 7. 已有证据

| 证据 | 状态 | 结论 |
|---|---|---|
| 真实数据 seeds 50--69 | 已完成 | 代表点选择器 20/20 命中高 accuracy 分支 |
| 坐标单轴符号翻转 seeds 70--79 | 已完成 | 30/30 随手性翻转为预期 determinant，并命中高 accuracy 分支 |
| 合成 determinant 真值验证 | 已完成 | 1600 cases 总准确率 0.995；normal 条件 1.0；错误集中在 learned_soft + near_degenerate seed 42 |
| 文献新颖性检索 | 初步完成 | 经典 Procrustes / Kabsch / Wasserstein Procrustes 已有；未发现“soft representatives + signed volume branch selection + HiWA/neural alignment”的完全同型方法，仍需人工精读确认 |

## 8. 证据边界

必须写清楚：

- 当前真实数据验证只覆盖一个 macaque neural--movement 数据集；
- 当前公式主要针对 $d=3,K=4$；
- 当前 representatives 刚好构成四面体；
- 当前 novelty 只是初步检索，不是最终查新；
- 合成实验验证的是 determinant branch recovery，不等价于证明真实神经数据普适有效；
- near-degenerate learned_soft 出现失败案例，说明 weak representative geometry 下仍有风险；
- 不能声称已经普遍解决所有 HiWA 分支问题；
- 不能声称已经完成自动 $K$ 或所有聚类方式消融。

## 9. 当前可写成的谨慎贡献

当前证据支持如下谨慎表述：

> 在当前神经--运动数据与固定 HiWA / Soft-HiWA 管线中，ROCA-HiWA 使用 soft cluster representatives 的有向几何结构，在不使用方向标签、测试 accuracy 或测试 $R^2$ 的条件下，稳定选择较高方向解码 accuracy 的正交分支，并在坐标手性翻转与合成 determinant 真值实验中表现出可解释的 determinant 选择行为。

## 10. 当前不能写成的结论

不能写成：

- ROCA-HiWA 已普遍适用于所有 HiWA 问题；
- ROCA-HiWA 已解决自动聚类数选择；
- ROCA-HiWA 已证明比所有 OT alignment 方法更优；
- ROCA-HiWA 的新颖性已经完全确认；
- near-degenerate 情况已经彻底解决；
- 当前真实数据结果可以直接作为最终论文主张。
