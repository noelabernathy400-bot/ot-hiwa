# ROCA 置信度分支：停止决策

## 决策

停止继续调节 ROCA 的行列式置信度、目标差距阈值或候选分支组合规则。当前证据表明，这一方向不是 96 样本无配对神经--运动对齐协议的主要瓶颈。

这不是对 ROCA 主体的否定，也不是对 Soft-GCOT 求解器收敛性的否定；它仅拒绝如下更窄的研究主张：**可以通过“代表几何符号与输运目标的实质冲突”可靠识别 ROCA 的高风险选择。**

## 冻结的跨子样本证据

子样本种子 `1001--1005` 在执行前冻结。每个实例从源域 803 个测试神经/运动行中无标签抽取 96 个源样本，并从 623 个训练运动行中无标签抽取 96 个目标样本；求解器初始化固定为 `0`。标签只在最后计算方向准确率和速度 \(R^2\) 时读取。

| 子样本 | Hard HiWA 准确率 / \(R^2\) | Soft-GCOT 准确率 / \(R^2\) | ROCA 准确率 / \(R^2\) | ROCA 选择是否较优 |
| ---: | --- | --- | --- | :---: |
| 1001 | 0.0833 / -2.3462 | 0.0833 / -2.3476 | 0.0833 / -2.3476 | 否 |
| 1002 | 0.1667 / -1.9435 | 0.1667 / -1.9259 | 0.1667 / -1.9288 | 是 |
| 1003 | 0.3229 / -0.4607 | 0.3333 / -0.4604 | 0.3333 / -0.4604 | 是 |
| 1004 | 0.2083 / -0.7153 | 0.2083 / -0.7152 | 0.2083 / -0.7152 | 是 |
| 1005 | 0.3646 / -0.8076 | 0.3646 / -0.8083 | 0.3646 / -0.8083 | 是 |

ROCA 的分支选择为 `4/5` 正确，但唯一错误（1001）没有触发事先冻结的冲突标记。该标记在五个子样本上拒绝 `0/5`，因此漏掉了 `1/1` 个实际错误。它不能作为一般性的置信度机制。

更关键的是，三种方法在每个子样本上的方向准确率几乎相同，且五个子样本的 \(R^2\) 全部为负。方向准确率从 `0.0833` 到 `0.3646` 的变化也远大于三种方法之间的差异。这说明当前失败主要来自数据实例/表示与无配对对齐目标的相容性，而不是从两个正交行列式候选中挑选分支的细节。

## 排除的后续工作

以下操作不会再在此协议上执行，因为它们无法解决已观察到的主导问题：

- 根据 1001 的结果调低或调高 \(1\%\) 目标差距阈值；
- 用方向准确率或 \(R^2\) 事后挑选 ROCA 分支；
- 扫描更多初始化 seed，并把它们误当成新的数据证据；
- 在固定 96 样本实例上继续微调 ROCA 的几何警告阈值。

## 可行的下一研究分支

若继续探索，应改变可检验的科学假设，而非继续优化选择器：

1. **表征/任务几何分支**：先用独立的源域监督或自监督信号构造可迁移表示，再检验 OT 是否改进目标任务；目标标签和真实配对仍保持评估专用。
2. **具有明确跨域任务语义的数据协议**：优先使用已有的 PAMAP2 时序域适配协议，而不是把当前无配对神经--运动样本强行解释为全局可旋转的同一几何对象。
3. **若保留当前数据**：先证明局部或条件化的对应关系可识别，再讨论 ROCA；在没有这种可识别性证据时，行列式选择的提升不具有解释价值。
