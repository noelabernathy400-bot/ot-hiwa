# PBMC 数据源与接入路线

## 1. 当前目标

为 CC-HiWA 选择一个比神经—运动任务更自然的跨模态匹配数据集。

目标数据：

> PBMC RNA–ATAC multiome。

目标接口：

$$
(X,Y,A,B,\mathcal{E})
$$

其中：

- $X$：RNA embedding；
- $Y$：ATAC embedding；
- $A,B$：无标签 soft components；
- $\mathcal{E}$：最终评价用的 paired cell ids / cell type labels。

## 2. 候选数据源

### 2.1 10x Genomics 官方 PBMC Multiome

来源：

- [10k Human PBMCs, Multiome v1.0, Chromium X, 10x Genomics](https://www.10xgenomics.com/datasets/10-k-human-pbm-cs-multiome-v-1-0-chromium-x-1-standard-2-0-0)

该页面说明数据来自健康男性供体 PBMC，并使用 Single Cell Multiome ATAC + Gene Expression 测序。

优点：

- 官方来源；
- 原始性强；
- 可作为最终论文数据源依据。

缺点：

- 数据较大；
- ATAC fragments / peaks 处理复杂；
- 第一版需要大量预处理，不利于快速验证 CC-HiWA。

### 2.2 Signac PBMC multiomic vignette

来源：

- [Joint RNA and ATAC analysis: 10x multiomic, Signac](https://stuartlab.org/signac/articles/pbmc_multiomic)

Signac 教程说明它使用公开 10x Genomics PBMC multiome 数据，演示同一批细胞的 DNA accessibility 和 gene expression 联合分析。

优点：

- 教程清楚；
- 数据处理路线成熟；
- 可作为我们理解 RNA/ATAC 预处理的参考。

缺点：

- 主要是 R/Seurat/Signac 生态；
- 对 Python-first 实验不是最省事。

### 2.3 scGLUE example datasets

来源：

- [scGLUE example datasets](https://scglue.readthedocs.io/en/v0.4.1/data.html)

该页面列出 `10x-Multiome-Pbmc10k`，包含：

- `10x-Multiome-Pbmc10k-RNA.h5ad`
- `10x-Multiome-Pbmc10k-ATAC.h5ad`

优点：

- Python 生态友好；
- h5ad 可直接用 AnnData/Scanpy 读取；
- RNA 和 ATAC 已拆成两个模态；
- 更适合第一版 CC-HiWA smoke experiment。

缺点：

- 需要核验 h5ad 中是否包含 cell type labels；
- 若只含 feature matrix，需要自行做 embedding 和软分组；
- 最终论文仍应追溯到 10x 官方数据源。

## 3. 当前推荐路线

第一版采用：

> scGLUE `10x-Multiome-Pbmc10k` h5ad 数据。

理由：

1. 我们现在要验证 CC-HiWA 是否在自然跨模态匹配任务上有生命力；
2. 不应一开始把大量精力放在 ATAC raw fragments 处理；
3. h5ad 能快速转成 $X,Y,A,B$；
4. 如果第一版有效，再回到 10x 官方源做更严谨复现。

## 4. 第一版数据处理计划

### 4.1 输入

下载或读取：

```text
10x-Multiome-Pbmc10k-RNA.h5ad
10x-Multiome-Pbmc10k-ATAC.h5ad
```

### 4.2 生成 embedding

第一版：

- RNA：PCA embedding；
- ATAC：LSI 或 PCA embedding；
- 维度：先用 20 或 30 维；
- 共同维度必须一致。

### 4.3 生成 soft components

第一版使用现有 `soft_groups.py` 风格的 prototype learning 或 GMM/KMeans softmax 距离：

$$
A_{ik}\propto \exp(-\|x_i-c_k^X\|^2/\tau)
$$

$$
B_{jl}\propto \exp(-\|y_j-c_l^Y\|^2/\tau)
$$

先固定：

$$
K=L=8
$$

后续再考虑自动 K。

### 4.4 运行 CC-HiWA

使用：

$$
S=A P B^\top
$$

$$
C^{CC}=C^{base}-\beta\log(S+\epsilon)
$$

第一版不做 rotation：

$$
R=I
$$

因为 RNA/ATAC embedding 先在各自降维空间中比较，后续可考虑 Procrustes 或 CCA 对齐。

## 5. 第一版评价

### 5.1 paired retrieval

如果 RNA 和 ATAC 两个 h5ad 保留同一批 cell barcodes：

- 对每个 RNA cell，通过 transport / aligned embedding 找最近 ATAC cell；
- 计算是否找回同 barcode；
- 报告 Recall@1, Recall@5, Recall@10。

### 5.2 cell type transfer

如果有 cell type labels：

- 从 RNA 通过 transport 转移 label 到 ATAC；
- 或从 ATAC 转移到 RNA；
- 报告 accuracy, macro F1。

### 5.3 transport diagnostics

无标签诊断：

- transport entropy；
- compatibility distribution；
- group transport sparsity；
- beta sensitivity。

## 6. 风险

| 风险 | 处理 |
|---|---|
| h5ad 没有 cell type labels | 先做 paired retrieval |
| RNA/ATAC cell order 不一致 | 用 barcodes 对齐 |
| 文件过大 | 先抽样 1000--3000 cells |
| embedding 尺度不同 | 标准化或 whitening |
| CC-HiWA 仍不提升 | 记录为固定 embedding 后处理不足，考虑 CCA/projector |
