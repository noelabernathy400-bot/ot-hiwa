## 内容摘要

接手包包含：

- 项目一句话说明；
- 必读文件；
- 已完成数据、脚本和结果；
- 当前核心结论；
- 运行环境和复现命令；
- 不要重复做的事项；
- 推荐同学负责的任务；
- 交付格式；
- 代码安全边界。

任务单包含：

- P0 复现实验链条；
- A：2k top-feature / gene-activity 扩展；
- B：window-bp 消融；
- C：PBMC 实验结果总表整理；
- 不建议同学做的事项；
- 每次交付材料要求；
- 讨论时的判断标准。

发给同学的说明包含：

- 可直接复制的沟通文字；
- P0 复现命令；
- 同学需要回传的材料；
- 当面沟通口径；
- 最小拷贝文件夹清单。

## 关键决定

同学优先做低风险但有论文价值的扩展实验和消融实验；主线判断、方法命名、最终结论仍由用户和主负责 agent 复核。

## 风险

- 同学如果直接大改 core，可能影响已有神经 / PBMC 结果；
- 如果只调 $\beta$，容易重复已知负结果；
- 如果没有记录 tag / seed / JSON / PNG，结果不可追溯。

## 下一步建议

用户可直接把三个 Markdown 文件发给同学，并要求同学从 P0 复现实验链条开始。
