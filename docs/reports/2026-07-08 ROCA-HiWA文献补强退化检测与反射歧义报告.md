## 关键结论

- reflection / determinant branch 是 Procrustes/Kabsch/Umeyama 经典问题。
- condition number / eigenvalue / singular-value diagnostics 是 point-cloud registration degeneracy 文献中的常见思想。
- signed volume / oriented simplex 是经典几何和 chirality 判断工具。
- 当前未发现“soft representatives + oriented simplex/signed volume + HiWA/hierarchical OT/neural alignment determinant branch selection”的高度相同方法。

## 对 ROCA 写法的影响

ROCA 不应声称发明 determinant、signed volume、condition number 或 Procrustes。更合理的贡献定位是：

- 发现 HiWA/Soft-HiWA 在当前神经—运动任务中存在 $O(3)$ determinant branch instability；
- 将 soft representatives 用作跨域有向几何锚点；
- 用 oriented simplex 无标签选择 determinant branch；
- 用 representative simplex condition number 提供低置信 warning。
