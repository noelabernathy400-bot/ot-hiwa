# 2026-07-05 HiWA 软分组尝试计划报告

## 目标

在修改代码前，设计一套借鉴 TACO soft group assignment 与 prototype 机制的 Soft-HiWA 数学方案、代码结构、对照实验和继续推进标准。

- 新建本报告。

## 关键决定

- 第一版采用“先学习并冻结软分组，再运行加权 HiWA”的两阶段方案，暂不直接端到端联合优化。
- 不修改作者 `PyHiWA` 原始代码；新模块放入 `Experiments/hiwa_python_reproduction/scripts/`。
- TACO 原型用于产生软归属并可辅助初始化，但不替代 HiWA 的组内样本传输 $Q_{ij}$。
- 第一轮固定 $K=4$，先隔离软与硬分组差异；自动选 $K$ 后置。
- 核心对照为同一原型下的 `argmax` 硬分组与连续软分组，以识别软权重本身的贡献。
- 使用配对随机种子和多次重复，真实方向标签只用于 Oracle 上界及最终评价。

## 已核验依据

- TACO PDF 第 4-5 页：可学习原型、逐行 softmax 归属、重构与熵目标、带权软组经验测度、组级 $P$ 与组内 $Q_{ij}$。
- HiWA Python 源码：当前通过硬标签布尔切片构造簇，并在 `_subspace_alignment_solver()` 中使用均匀簇内边缘质量。
- 现有复现结果：方向准确率对随机初始化敏感，适合作为软分组稳定性实验的主要观察对象。

## 风险或跳过事项

- 本次只制定计划，没有修改算法代码或运行新实验。
- TACO 原文没有显式温度参数；计划中的 $\tau$ 是本项目为控制软度增加的扩展。
- 第一版不解决自动组数、端到端编码器、任务监督、图正则和计算稀疏化。
- 软组在每个组对中使用全体样本，计算成本会高于硬簇版本。
