## 关键决定

- 当前方法冻结为 Representative-Oriented Component-Aware Soft-HiWA，简称 ROCA-HiWA。
- 当前主贡献聚焦在无标签 determinant branch selection，而不是继续调 temperature 或追求单次最高 accuracy。
- 合成验证采用 true_det、noise、assignment_mode、degeneracy_mode 网格，保留失败案例。
- 文献结论只写成初步检索，不声称最终 novelty proof。

## 验证结果

- `python -m unittest discover -s tests -v`：16/16 tests passed。
- 合成 determinant validation：1600 cases，总准确率 0.995。
- normal 条件下 oracle_soft 与 learned_soft 均 1.000。
- near_degenerate + oracle_soft 为 1.000。
- near_degenerate + learned_soft 为 0.980，8 个失败集中在 seed 42。

## 风险与跳过事项

- 当前真实数据仍只有一个猕猴神经—运动数据集。
- near_degenerate 在 selector 标准化后未触发 hard degeneracy flag，说明退化检测需要 refinement。
- 文献检索仍需进一步全文核验，尤其是 TACO、reflection ambiguity、chirality-aware registration 和 neural manifold alignment。
- 没有新增 K=5、聚类消融、温度大扫参、标签损失或端到端训练，避免偏离冻结协议。

## 下一步建议

1. 优先做退化检测 refinement：raw volume、standardized volume、simplex condition number、assignment entropy、Hungarian margin。
2. 系统补 TACO 与神经流形对齐文献。
3. 选择一个最小外部数据/跨 session 场景验证 ROCA 是否泛化。
4. 在上述完成前，不建议改变主实验协议。
