# 2026-07-06 HiWA 代表点定向正交分支选择实验报告

## 目标

将上一阶段发现的 $O(3)$ 正负行列式分支问题转化为可复现的双候选算法，并设计
不使用方向标签的自动分支选择规则。

## 代码改动

- `scripts/soft_hiwa.py`
  - `_closed_form_rotation` 支持精确约束 `determinant_sign=±1`；
  - 全局与局部 Procrustes 更新使用相同分支；
  - 新增运输目标、正交误差和局部—全局共识诊断。
- `scripts/run_soft_neural.py`
  - 传递分支约束并保存新增诊断。
- `scripts/run_rotation_stabilized.py`
  - 退火链支持可选 determinant sign。
- 新增 `scripts/run_component_aware.py`
  - 生成 det=±1 两个候选；
  - 可选反向拟合；
  - 实现代表点有向体积分支选择器；
  - 保存逐阶段、逐候选和选择器结果。
- 新增 `scripts/analyze_component_confirmation.py`。
- 新增 `scripts/analyze_representative_confirmation.py`。
- 测试增加指定行列式闭式解和代表点反射识别。

## 实验链

### 1. 机制种子 7、8、24

- det=-1 三次均为高准确率候选；
- det=+1 三次均为低准确率候选；
- 双向运输目标在这三个种子上 3/3 选对。

### 2. 双向运输目标确认 Seeds 30–49

预注册规则失败：

- 只选对 7/20；
- 平均方向准确率 0.47111；
- 未达到 0.55 的预定门槛。

该负结果完整保留，没有继续调整目标权重。

### 3. 代表点有向体积假设

读取 Seeds 30–49 后提出 TACO 启发的代表点有向体积规则：

`sign(det(X_rep) * det(Y_rep))`。

由于属于事后提出，Seeds 30–49 只作为开发证据。

### 4. 冻结规则确认 Seeds 50–69

- selector 与标签事后 oracle 一致：20/20；
- 平均准确率：0.57753 ± 0.00324；
- 最低准确率：0.57303；
- 平均 R²：0.59934 ± 0.00396；
- 20/20 高准确率分支；
- 0 个灾难性 R²；
- 0 个代表点退化；
- 五项预注册标准全部通过。

相对 prototype-hard 的配对平均差：

- accuracy +0.05891，Bootstrap 95% CI [0.02464, 0.09390]；
- R² +0.01950，Bootstrap 95% CI [0.00922, 0.03062]。

## 关键判断

- 原 HiWA 目标近似无法区分两个反射分支，训练损失、共识误差和 cycle consistency
  均不是可靠选择器。
- 四个软簇代表点在三维空间形成有向四面体，可提供原目标缺少的 handedness 信息。
- 当前方法在独立随机种子上成立，但仍是单数据集证据。
