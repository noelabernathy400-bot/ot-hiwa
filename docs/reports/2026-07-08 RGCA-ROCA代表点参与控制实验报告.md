## 关键决定

- ROCA 和 RGCA 不拆成互斥方法，而是合成 `RGCA-ROCA-HiWA`。
- `lambda=0` 作为旧 ROCA-HiWA 对照。
- `lambda>0` 时，representative cost 作为 group transport 的弱正则项。
- 放弃最初“local cost 和 representative cost 归一化后凸组合”的强引导版本，因为 smoke run 显示大权重会导致 $R^2$ 灾难性下降。
- 当前采用加性弱引导：

$$
C^{guided}=C^{local}+\lambda s(C^{local})\widetilde{C}^{rep}
$$

## 验证结果

- 修改后单元测试：`python -m unittest discover -s tests -v`
- 结果：27/27 passed。
- quick seeds 50-59：
  - `lambda=0.01` 相对 `lambda=0`：direction accuracy +0.000963，movement $R^2$ +0.002418。
  - ROCA 10/10 选中高 accuracy 分支。
- pilot seeds 50-54：
  - `lambda=0.01` 相对 `lambda=0`：direction accuracy +0.000963，movement $R^2$ +0.000714。
  - ROCA 5/5 选中高 accuracy 分支。

## 风险和跳过事项

- 当前增益很小，不能声称显著提升。
- 大 `lambda` 有破坏连续运动对齐的风险。
- 尚未跑完整 seeds 50-69 pilot。
- 尚未分析 transport matrix 是否在结构上更接近 representative matching。

## 下一步建议

1. 固定 `lambda=0.01` 跑完整 seeds 50-69 pilot。
2. 增加 transport structure analysis，比较 `lambda=0` 和 `lambda=0.01` 的 $P$ 是否更清晰。
3. 如果完整结果稳定，再把 `RGCA-ROCA-HiWA` 写入论文方法主线。
4. 如果完整结果不稳定，转向 sample-level GCOT，而不是继续加大 representative guidance。
