# Hyser 研究目标、数据泄漏纠正与统一评价规范

更新日期：2026-11-17。此文档记录用户确认的科研目标和迄今实验结果的证据地位，不代表重新运行了模型。

## 一、主要研究问题

在**训练时不知道真实跨模态样本或簇对应关系**的前提下，软分组能否比硬分组**更可靠地降低跨模态分布之间的距离**？

- 一级指标：统一参考经验分布上的 Wasserstein-2 距离，评价两组点云整体分布是否更接近。
- 二级指标：真实同步对应下的 R²、相对平方误差与平均欧氏距离，评价逐点物理对应恢复情况。
- 辅助诊断：各自训练时的层级 OT 代价、簇级 P、Sinkhorn 边缘误差、ADMM 旋转变化与局部共识残差。

## 二、完全无监督：对训练信息的精确定义

源域 X 和目标域 Y 分别拥有自身观测点云。允许两域分别 PCA、标准化、白化、独立 K-means、独立学习软隶属；允许自由优化 P、Q、R。

训练或选择超参数时**不允许**使用真实同步窗口索引及其导出的对应信息；不允许给目标域复制源域标签、令目标隶属 B=A、强制 P=I4/4、通过同步配对指标选择最好的种子或初始化。

**可视化例外：**在模型训练完毕后，可使用真实同步索引让两边同色代表同批物理样本。此时颜色只用于绘图与事后评价，不能反向进入拟合。

历史实验将可视化所需的标签继承误用于目标域训练，构成**组对应信息泄漏**。该部分所有数字必须保留但归入**组级监督诊断**，不应当被称为无监督性能结果。

## 三、为何原先的 OT 降幅不能直接排 Hard/Soft

算法内部层级运输平方距离项为

\[
C_{\rm hierarchical}=\sum_{k,\ell}P_{k\ell}\sum_{i,j}
Q^{k\ell}_{ij}\left\|\frac{R x_i-y_j}{\sqrt3}\right\|^2.
\]

此前存档的代价不含熵正则项。Hard 与 Soft 的簇质量分布和组权重不同，即使它们各自对齐前后明显下降，也**未必是在同一个目标函数上比较**；可作为每个模型的优化诊断，不能单独证明哪种算法分布对齐更好。

## 四、正式比较用同一个外部 W₂²

全部250个真实白化三维样本固定等权经验分布：

\[
\widehat\mu_X=\frac1{250}\sum_i\delta_{x_i/\sqrt3},\quad
\widehat\mu_Y=\frac1{250}\sum_j\delta_{y_j/\sqrt3}.
\]

统一评价每个已训练的正交变换 R：

\[
E_{\rm common}(R)=W_2^2(R_\#\widehat\mu_X,\widehat\mu_Y)
=\frac1{250}\min_{\sigma\in S_{250}}
\sum_{i=1}^{250}\left\|\frac{R x_i-y_{\sigma(i)}}{\sqrt3}\right\|_2^2.
\]

这是完全**不使用样本真实配对**、也不使用模型组标签或簇级 P 的共享评价指标。250×250且两边等权，可用 Hungarian 线性分配求精确无熵最优运输。对所有模型使用相同全精度 X/Y、相同1/√3缩放、相同原点参照 R=I。

报告对齐前 E_common(I)、对齐后 E_common(R)、降幅百分比，按相同5个随机种子汇总平均值、标准差和逐种子胜出次数。

R²仅作为二级评价，不应用于选择主任务的模型参数。若再使用独立试次，请分离训练时参数选择与最终评价。

## 五、现有结果的准确归类（历史数据保留原值）

| 实验 | 是否已知真实组对应 | 已保存数据与结论 | 证据地位 |
|---|---|---|---|
| Hard 源域 K-means、目标继承标签，自由/固定 P | 是 | Hard固定 P：R²=-0.153907；内部层级 OT 1.384391→0.835982；自由 P 内部 OT 1.385820→0.843677 | 组级监督诊断 |
| Soft 源域分组、目标继承隶属 B=A | 是 | Soft K-means τ=.5：R²=-0.150957；Soft原型 R²=-0.142562 | 组级监督诊断 |
| Hard/Soft 两域独立学习分组，P 自由 | 否 | 五种子平均同步 R²：Hard=-0.92003，Soft K-means=-0.86820，Soft原型=-1.04793；平均各自OT后成本分别0.41937、0.44569、0.51350 | 目前可作为无监督探索性对照，但尚未完成统一外部W₂²排名 |

自由独立分组 Hard 的 seed42 内部层级 OT 运输项为2.36079→0.39606，下降约83.2%，说明**该模型自身的OT成本显著下降**；并未证明 Soft 相对于 Hard 获得同样程度或更高的共同指标改善。

各方法的独立分组五个种子均通过此前指定的旋转变化、共识和边缘质量残差检查；这不等于非凸优化达到全局最优。五个种子也不是五个独立试次。

## 六、实验来源与尚未完成的验证

全部历史求解结果来自用户上传的 GCOT/HiWA 公式的本地数值转录，而非直接导入并执行 GitHub 原文件；四乘四组级OT部分改为数学等价的高精度对偶数值求解。旧的组级监督和独立无监督实验数字均原样存档，不重新标榜为原代码直接复现。

**下一项任务：**在相同全精度250点数据上重新保存各个无监督方法每个种子的完整正交矩阵 R，使用统一指标计算共同 W₂²。当前仓库中的独立实验五种子 CSV/摘要只包含指标，没有包含全部15个最终 R；在补齐矩阵前不得伪造统一W₂²数值。随后以同数据同数值准则比较 Hard-vs-Soft，在独立试次上验证。
