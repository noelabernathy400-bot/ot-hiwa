# Hyser 跨模态对齐实验过程笔记

日期：2026-11-17 · 数据：PhysioNet Hyser v2.0.0 / random_dataset / subject01_session1 / sample1。

## 0. 项目演变与选择依据

之前先试过 Paderborn K001：只有一只健康轴承在四种稳定工况下的振动和两相电流。虽然某些特征的工况分组清楚，但振动与电流的跨域簇间距离响应不同；稳定离散工况也不足以充分检验 Soft-GCOT 的边界保留优势。那些实验**不是 Hyser 实验结果**。

随后选择 Hyser：256 通道前臂高密度肌电与五根手指力同步测量，任务是随机/自由组合的手指用力，较有机会产生连续过渡和局部重叠。**自然重叠是研究动机，不是预先得到的软分组优势证据。**

研究问题：无配对训练条件下的 Hard HiWA 能否恢复肌电表示与力量表示的共同低维结构？分组边界不一致是否成为瓶颈？Soft-GCOT 能否在共同表示和严格对照下改善？

## 1. 原始记录

用户从 PhysioNet 官网上传的真实文件：
- `random_preprocess_sample1.dat/.hea`：256 通道，2048 Hz，51,200 行（25 s）。
- `random_force_sample1.dat/.hea`：5 通道，100 Hz，2,500 行（25 s），上传副本的实际名称曾为 `random_force_sample1(1).dat`。
- `random_raw_sample1.dat/.hea`：原始肌电备份；**首轮实验使用 preprocess，而非 raw**。

两个模态**采样率不同**，通过相同的时间窗口构造同步特征，而不是把 2048 Hz 采样点一对一映射到 100 Hz 采样点。

仅有 trial1，没有独立试次：按时间先后使用前 200 个窗口训练、后 50 个窗口探索性检验。这个 50 个窗口是同一试次末尾 5 秒，**不能称为独立试次泛化结果**。

## 2. 预处理（全部训练拟合、测试仅应用）

- 固定每窗 0.1 s；每窗肌电每通道计算去均值 RMS（256 维）。
- 对肌电 RMS 使用 `log1p(RMS * 1e5)`（固定尺度），只在 200 个训练窗口上拟合通道级 StandardScaler。
- 对标准化后的 256 维肌电训练窗口拟合 PCA(3)。训练解释方差比 `0.8389806359, 0.0677917856, 0.0266908321`；合计 **93.3463%**。
- 五指力量取同窗均值；按**训练期方差**选拇指、**中指、食指**（thumb, middle, index）三维；不按对齐准确率选择。
- 两个域分别中心化、做一次**全局标量**归一化，保留域内各方向的相对尺度；原始物理单位/转换按 WFDB 头文件，避免无依据称为牛顿。
- 电流/力域（本次是力量域）在训练和留出内部独立打乱行序；同步窗口编号只用于**评价**。

结果：两组各 250 个三维点，训练 200×3、探索性留出 50×3。K=4 为探索性指定超参，不对应四个真实手指状态。

## 4. 旧 Hard HiWA 探索（`hard_hiwa_adapted.py` 重实现）

**不是直接运行本仓库原 `HiWA` 类。** 实现包含局部簇内 OT、簇级 OT、局部旋转和 ADMM，但相比项目源码具有不同归一化、丢失 `1/sqrt(3)` 嵌入缩放、不同 Sinkhorn 预算和收敛阈值。

- 数据：200 train + 50 holdout，三维。
- 试验过 `mu={0.05,0.5,2.0}`。最后选 `mu=2` 延长到 110 次外层迭代（根据**训练残差**，而不是挑测试准确率）。
- 110 次：整体局部—全局共识残差 **0.0131633**，全局旋转变化 **0.0224133**；没有同时满足既定阈值。
- 旧运行留出跨域硬簇一致率 **18.0%**，留出 Top-1 **2.0%**，Top-5 **8.0%**；配对平均距离 **1.6117**，随机打乱配对距离 **1.4289**。
- 结论：旧运行未收敛，不可作为原项目 Hard HiWA 的正式负结果。

## 5. 与原仓库代码逐项核对及复测

已实际检查原仓库 `src/hiwa/hiwa.py` 与原神经基线 `experiments/hiwa/run_taco_faithful_baseline.py`。确认区别：

| 项目 | 原项目既有确认实验 | 旧 Hyser 重实现 | 参考风格复测 |
|---|---|---|---|
| 源码 | `src/hiwa/hiwa.py` | 独立重实现 | 独立重实现，恢复关键设置 |
| 正规化 | 协方差白化 | 分域整体尺度 | 训练数据白化 |
| 嵌入缩放 | `1/sqrt(d)` | 未缩放 | `1/sqrt(3)` |
| ADMM μ | 0.05 | 2.0 | 0.05 |
| 外层最大迭代 | 200 | 110 | 150（在60停止） |
| 局部交替上限 | 40 | 10 | 40 |
| 簇内/簇级 Sinkhorn | 80 / 300 | 50 / 200 | 50 / 200 |
| 双残差容差 | 0.01 | 另设 | 0.01 |

上述不是单变量消融，**不能断言其中某项就是未收敛的唯一原因**。原先 10 次局部迭代在初始若干簇对已数值稳定，故“局部次数少”也不是已证实的根因。

真实 trial1 上参考风格修正：第 **60** 次外层迭代满足 **整体局部-全局残差 0.0094757** 与 **全局旋转变化 0.0001616**，均小于 0.01（`mu=.05`, 训练集白化、`1/sqrt3` 嵌入缩放）。

**限定语：**这是一份“原项目风格重实现”的 ADMM 收敛测试，既非逐行原版运行，也非正式 Hard/Soft 对比；簇级 Sinkhorn 最大边缘质量误差仍约 `3.32e-4`，高精度检查未完成。

## 6. 几何及恢复能力评价（仍为参考风格重实现）

- 训练跨域簇一致率：**16.5%**；同一试次末尾留出：**20.0%**。
- 留出时间窗 Top-1 检索：**2.0%**，50 个候选的随机命中基线亦为 2.0%；Top-5：**10.0%**。
- 已知训练同步配对下的 oracle 正交 Procrustes 相对误差：**1.0523**；同一训练 oracle 在留出上的相对误差 **1.7172**。
- 训练两域成对距离相关性：**0.2337**。
- 训练数据时滞扫描最佳约 +0.1s，oracle 残差约 0.9627；尚未在独立试次验证，不可据此做最终时滞修正。
- 依真实同步窗口事后拟合最佳**硬簇标签排列**：训练 42%，留出 50%。这是**利用答案的 oracle 诊断**，不是无监督方法结果。

**判定：**
1. 数值：复测 ADMM 达到双残差容差；
2. 任务：跨模态点对及簇对应仍失败；
3. 数据表示：当前三维表示可能缺乏近似等距几何，或存在响应延迟、模态噪声；
4. 研究结论：不应说“原始 Hard HiWA 已被证明失败”，更不能直接宣称 Soft-GCOT 会改善。

## 7. 何为「完成基线」和后续实验

1. 在本仓库实际运行原 `HiWA` 类，不借用重实现结论；检查局部 OT 边缘、簇级 OT 边缘、全局变化、**最大局部共识残差**及可重复性。
2. 取得 subject01/session1 的 sample2–5，按完整试次留出、训练上估计肌电→力量滞后；严格冻结特征/划分。
3. 同一数据、分组数、随机种子与停止规则上比较原始 Hard HiWA 和 **full-support Soft-GCOT**；分组软化以外其他超参尽可能对齐。
4. 明确报告：收敛率、簇一致率、样本检索、paired oracle vs unsupervised、特征等距诊断、软分配熵。
5. 当前没有 Soft-GCOT 真实实验结果，不应在图表或论文中填写。
