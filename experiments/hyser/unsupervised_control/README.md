# Hyser：真正无监督的 Hard / Soft 两层 OT 实验

> **本目录的全部实验、报告、评价脚本和今后新增的运行，必须服从 [上级 Hyser 实验总 README](../README.md) 和 [正式研究评价合同](../RESEARCH_OBJECTIVE_AND_EVALUATION.md)。**

## 研究目标与指标

此项目研究的是 **两层层级最优传输**：第一层由组级 P 学习簇与簇的运输，第二层由每对簇内的 Q^{kℓ} 学习样本质量运输，再通过正交变换 R 对齐。**不能把这一目标缩减为普通整体 W₂²。**

每次正式实验必须报告：完整 P、每个 Q、簇对运输成本矩阵、两层加权纯运输 T_hier、**含组内熵与簇级熵的完整目标 J_hier**、所需的收敛及边缘误差；并保留全部点云统一无熵 W₂² 作为外部辅助指标、同步点 R² 作为次要诊断。

- 现有 [RESULTS.md](RESULTS.md) 保存两域独立组学习和自由 P 的原始运行结果，其中已有层级成本多为**不含熵的运输项**。
- [COMMON_W2_RESULTS.md](COMMON_W2_RESULTS.md) 和 [SOFT_TEMPERATURE_SWEEP.md](SOFT_TEMPERATURE_SWEEP.md) 保存普通整体 W₂² 以及温度消融；这些数值有效但**不构成两层层级目标的最终性能排名**。
- 全部旧运行和参数、种子、P/R 可复核；过去未保存所有簇内 Q 或完整熵目标的条目，必须明确标注**待补算**，禁止凭 W₂² 值代替。

## 必须隔离可视化与训练

**训练中 X/Y 分别独立学习硬组或软隶属，B 不得从 A 复制，P 不得由真实同步关系固定。** 真实样本配对仅允许在训练结束后用于评价及绘图时让两域相同颜色代表同步的同一批物理样本；可视化 K-means 参考标签必须与训练分组变量完全隔离。

全部二维/三维图、数值日志、完整超参数、收敛情况及源码来源应存档；只用全精度数据算指标，不用仅供绘图的量化坐标复算。原数值求解主要是根据GCOT公式的本地移植，非直接执行远程原始类；已实施的 ADMM 残差检查不等于达到全局最优。当前仅有一个25秒试次，多随机种子不等于跨试次检验。
