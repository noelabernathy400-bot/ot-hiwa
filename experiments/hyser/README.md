# Hyser 实验总规范：无监督双层层级 OT（必读）

> **2026-11-18 研究合同，适用于后续所有 AI 协作者、代码修改和实验报告。** 本项目的核心模型是 **簇级 P + 簇内 Q 的两层层级最优传输**；整体经验 W₂² 必须保留，但**不能代替**层级 OT。旧实验里出现过把绘图用同步颜色误送入训练的严重数据泄漏，严禁再次发生。下方保留的“仅源域 K-means→目标继承标签”属于**历史组级监督诊断**，并非正式无监督协议。

## 一、研究目标与指标优先级

**核心研究问题：**在完全不知道跨模态真实样本配对、真实簇对应关系的条件下，Soft-GCOT 能否相对 Hard HiWA 提升**双层层级 OT** 的对齐质量与稳定性？

今后每次实验必须同时报告如下指标，缺失项须写明“尚未计算”，不得用其他指标代替。

| 项目 | 具体内容 | 地位 |
|---|---|---|
| **第一层（组级）** | K×K 簇对成本矩阵 C、组级传输 P、P 的行列边缘误差/熵 | **核心** |
| **第二层（簇内）** | 全部 Q^{kℓ}、簇内 OT 成本及每个 Q 的边缘可行性 | **核心** |
| **层级纯运输项** | T_hier = Σ_{kℓ} P_{kℓ} 〈Q^{kℓ}, D^{kℓ}(R)〉，对齐前后各一值 | **核心**；不包含熵项 |
| **完整层级目标** | J_hier = T_hier + ε_s Σ H(Q^{kℓ}) + ε_g H(P)，三项分别报数 | **核心**；需说明熵约定 |
| **共享层级参考评价** | 事先固定的、无同步监督的独立两域参考分组测度；给各法 R 重新优化评价用 P、Q，评估同一个参考层级目标 | **重要对照**；仅比较该参考下的 R，不足以单独衡量软分组本身 |
| **统一整体 W₂²** | 在所有原始点等权、同一坐标尺度上精确计算普通经验 W₂² | **必须保留的辅助**，不代替 P/Q |
| 同步配对指标 | 训练结束后的 R²、相对平方误差、平均 L2 | 次要诊断，不参加调参/训练 |

使用行样本约定 X Rᵀ、d=3 时，D^{kℓ}_{ij}(R)=‖(x_iRᵀ−y_j)/√d‖²。Hard 的各簇子集样本等权，Soft 的 A、B 分别经每组归一化为概率质量；P 的行、列边缘目前均为 1/K（K=4）。Q^{kℓ} 的行列边缘分别为 a^k、b^ℓ。必须注明局部 R_{kℓ} 与最终全局 R 的区别，**不能拿局部簇对成本冒充全局旋转的运输代价**。

采用代码中的负 Shannon 熵约定 H(M)=Σ M log M，0 log 0=0。原 GC-OT/gcot/alignment.py 的目标记录在 retain_plans=True 时使用未额外乘 P 的 ε_sΣH(Q) 和 ε_gH(P)；局部 Sinkhorn 温度为 ε_s/P_{kℓ}。ADMM μ 是求解参数，不是目标函数的一项。数值更新未被证明在每一步都严格降低完整 J，不能无证据作此声称。**只有 R、P 没有 Q，无法复原训练最后一步真实完整目标**；事后重新优化 Q 必须另标“全局 R 下的事后评估”。

公平性要求：不同 Hard/Soft 分组定义了不同的概率测度，原生 T_hier、J_hier **不能仅凭绝对值直接跨方法排名**；同一方案对齐前后须保持分组及 P 等口径一致，并标明 P/Q 是固定还是重优化。共享参考分组应先确定，建议使用多个无监督参考组划分以检查敏感性；共同 W₂² 是同一分布指标，但只评价整体，不评价层级结构本身。

## 二、训练与可视化必须物理隔离（禁止泄漏）

1. **正式 Hard：**源域 X、目标域 Y 分别独立进行 K-means/其他明确指定的硬分组；不得让目标训练标签继承源域标签。
2. **正式 Soft：**源域独立估计 A，目标域独立估计 B（Soft K-means/GCOT 原型需说明具体方案）；**禁止 B=A** 或按真实同步索引传递概率。
3. **自由簇对应：**P 必须由层级 OT 自主学习；严禁以真实同步标签初始化/固定 P=I_K/K，也不得用真实组重叠或真实点对应确定簇排列。
4. **监督信息禁区：**真实同步行号、配对标签、配对 Oracle、配对 R²、组重叠 O=AᵀB/n 不得进入训练、初始化、超参数或随机种子的选择。
5. **画图时的唯一例外：**模型训练完成并冻结后，**只在源域执行一次绘图参考 K-means**，将其可视化标签按真实同步样本索引传到目标域着色，使两图同色表示同批物理样本。此标签只存在于可视化变量中，**绝不可写入训练簇标签、A/B、P/Q 或目标优化代码**。
6. 绘图必须提供前后 2D 和 3D，左右两域颜色语义一致、坐标和视角可比较；图注明确“相同颜色为后处理的同步参考组，不代表训练组对应”。

历史上违反以上规则的实验及其图片和数字**保留**，但必须标记“组级监督/已知对应诊断”，不能作为无监督 Hard/Soft 胜负证据。不得覆盖或静默篡改历史实验。

## 三、统一数据与数值条件

- 数据：PhysioNet Hyser subject01/session1/random sample1；EMG 256 通道 2048 Hz、手指力量 5 通道 100 Hz，25秒内以0.1秒为窗获得250对数据。EMG 按 RMS→log1p→逐通道 StandardScaler→PCA 3D；力量取 thumb/middle/index 同窗平均；两个域分别协方差白化至三维均值≈0、协方差≈I。
- 固定特征、归一化与训练输入；当前可比无监督对照使用 d=3、K=4、X/√3、Y/√3、μ=0.05、ε_s=0.1、ε_g=0.2、最多100次局部更新、150次簇内 Sinkhorn、180次外层迭代、种子40–44。原 TPAMI GCOT 也存在不缩放版本，不能直接混比。温度 τ=0.25/0.5/1.0 与原型 λ_h=1 必须按具体分组方案注明。
- 每次记录随机种子、完整 P、可复核的 Q（或缺失说明）、R、簇对成本、两层运输、两个熵项、整体 W₂²、完整参数和计算代码/commit。
- 收敛必须报告旋转变化、局部与全局 R 的共识残差、ADMM 对偶残差及容差、P/Q 边缘误差、P变化量和旋转正交误差；**不能把“达到最大迭代数”或只满足旋转变化阈值当成严格收敛**。先前记录的 ΔR≤0.01、共识≤0.01、边缘≤1e−6 只是简化数值检查，不等同完整 KKT/全局最优。
- 可视化坐标是量化近似，**不能用来重新拟合或冒充全精度误差**。此前 Hyser 多数计算是根据上传的 HiWA/GCOT 公式实施的**本地数值移植**（4×4组级 OT 用高精度等价对偶求解），不是直接执行远端原代码；需按实际运行方式标注。
- 五个种子属于**同一25秒试次的多初始化**，不是五个独立试次；尚缺跨试次/受试者验证。同步配对只能在训练完成之后作为补充评估。

# Hyser：源域唯一 K-means → 目标继承标签 → Hard HiWA

**版本：2026-11-17。此目录取代原先 Hyser 的各域独立聚类实验及其图片。**

真实 PhysioNet Hyser 受试者01、session1 的 Random Task sample1。256通道肌电2048Hz、五指力量100Hz，同步25秒。以0.1秒切窗获得250对样本。肌电做窗口RMS、log1p、通道标准化、PCA3；力量选thumb/middle/index三指窗口均值。两域分别协方差白化成3D，均值约0、协方差为单位阵。
