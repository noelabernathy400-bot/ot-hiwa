# Hyser 无监督双层层级 OT：完整实验与多方法对照

**实验日期：2026-11-18。** 使用真实 Hyser subject01/session1/random sample1 的 250 个同步窗口（训练时**完全隐藏同步关系**），分别白化到三维。基础模型 Hard HiWA（两域独立 K-means）与 Soft-GCOT 式 Soft K-means / 原型分组均使用簇级 `P` + 簇内 `Q[k,l]` + 全局正交 `R`。新增对照：**SA、WA、DAD 三维适配版、HiWA-SSC、HiWA-GMM**。全部数值由实际运行或历史真实运行保存的参数复算；不包含虚构的算法得分。

## 研究问题及结论

**主要问题**：在完全不知道源–目标真实配对/组匹配的情况下，软分组是否相对于硬分组改善两层层级 OT 的对齐？**不是**仅比较普通点云的 `W₂²`，而是同时报告两层加权运输成本、完整熵正则目标、外部共同参考层级得分与整体 `W₂²`。

结论：在两域独立 K-means 作为参考层级时，Hard HiWA 与 Soft K-means（τ=0.25）几乎完全持平，DAD 的三维适配也接近；Soft 原型及 HiWA-SSC/GMM 在该参考下较差。不过参考分组的改变**会影响排名**：在两域独立 GMM 的参考层级下，HiWA-GMM 与 Soft 原型的得分好于 Hard。因此，目前无法得出“Soft 一概优于/劣于 Hard”的普遍结论。本结果只覆盖一个真实25秒试次、五组随机初始化，而非跨受试者统计结论。

## 正确的信息边界

- 正式 Hard：源域/目标域**各自独立**聚类；正式 Soft：各自独立估计软隶属 `A` 和 `B`，**不允许 B=A**。
- 簇级 `P` 自由优化；不使用真实同步索引来固定组对应、选择种子、初始化、调超参数。
- 为了**最终散点图着色**，在模型全部训练结束后，单独对源域 K-means，才将同一时间窗的颜色赋予目标域。训练代码不读取图形标签；源域和目标域图中同色仅代表同批物理样本，并不代表算法学到了组匹配。
- 之前“目标域继承源域训练标签、甚至固定 P=I4/4”的实验保留为**组级监督诊断**，完全不混入本表。

## 完整两层目标与计算口径

在全局旋转 `R` 上，坐标采用 `X/sqrt(3)`、`Y/sqrt(3)`：

\[
C_{k\ell}=\sum_{ij}Q^{k\ell}_{ij}\left\|\frac{x_iR^\top-y_j}{\sqrt3}\right\|^2,\quad
T_{\rm hier}=\sum_{k\ell}P_{k\ell}C_{k\ell}.
\]

\[
J_{\rm hier}=T_{\rm hier}+0.1\sum_{k\ell}H(Q^{k\ell})+0.2H(P),
\quad H(M)=\sum_{ij}M_{ij}\log M_{ij}.
\]

其中 P 行列和各为 `1/4`，每个 Q 的边缘与各自分组的条件归一化概率质量相等。簇内 Sinkhorn 温度是 `0.1/P_kl`，簇级熵权重为 `0.2`。

**重要说明**：本轮重新求解每个已训练模型的最终**全局 R** 下全部簇对的 `Q`，对“原生层级”固定训练得到的最终 `P`，对“共享参考层级”再优化评价用的 `P,Q`。因此完整 `J` 的数值是**事后全局 R 下重新计算的目标**，不是原始 ADMM 最后一轮未存储的局部 `R_kl,Q_kl`；不得混称。前后对齐改变 `R` 时，在原生层级保持最终 `P` 一致并重新优化 `Q`，使前后口径相同。

不同 Hard/Soft 原生分组对应不同的概率质量与熵基线，原生 `T/J` 绝对数值不可直接跨方法排名。共享参考层级是两域**独立、无监督地固定同一参考簇划分/权重**，对所有学得的 `R` 重新优化评估所需 P/Q，因而比较的是统一参考下各自的全局旋转，并**不能单独评价 soft 分组本身贡献**。使用三个参考：独立 K-means、独立 Soft K-means（τ=0.5）、独立 GMM（均 seed 42）。整体点云 `W₂²` 保留为必需辅助指标，但不替代两层评价。

## 其他方法的来源与公平性限制

1. **SA**：依照用户 GitHub `GC-OT/gcot/baselines.py` 原方法的 **full-basis Subspace Alignment** 在3D白化特征上实现。白化使三维协方差本征值相等，PCA方向可能不稳定；此基线不具备良好方向可辨识性。
2. **WA**：依照同文件的 **Wasserstein Alignment** 随机正交初始化和退火 `γ:100→0.1`、200次外层/最多1000次 Sinkhorn，以匹配层级方法的三维距离尺度进行独立无监督拟合。
3. **DAD-3D 改编（不是作者MATLAB原程序）**：官方 [KordingLab/DAD](https://github.com/KordingLab/DAD) 为密度 KL 与旋转搜索，包括原版使用的大规模3D采样、后续平移/二维旋转及图形判断。当前压缩包中没有找到直接可用的 DAD 脚本；本实验按照官方 `gridsearch_3DKL.m` 思路，使用 `k=5` 邻居密度、`14³` 固定三维网格、`5³×2` 旋转/反射候选，并在零均值白化特征上省略平移。这是**明确带有改动、且不应作为论文中官方DAD准确复现**的探索性对照。
4. **HiWA-SSC**：源、目标分别用SSC谱聚类学习4个硬簇，按用户 GitHub 的 `gcot/grouping.py` SSC移植 + 两层P/Q ADMM实现；评价统一使用最终全局正交R。
5. **HiWA-GMM**：源、目标分别GMM学习4组，按照用户源码 `baselines.py / preprocessing.py`，使用源Isomap(2,12)辅助投影及目标前两维投影来训练层级对齐，输出全局R用于原始3D评价。它的训练几何与 Hard-Kmeans不同，须保留这一方法差异，不能将结果归因于分组方式一项。

**原始来源**：用户的 GitHub 历史实验分支 `experiments/dandi-000138-4d-hard-clustering-20261117` 中 `research/GCOT-reproducible-20261018/GC-OT/gcot/baselines.py`、`grouping.py`、`preprocessing.py`，以及 [KordingLab/DAD](https://github.com/KordingLab/DAD)。并非能证明用户之前 ZIP 中确实包含全部五个方法；实际可见的 `Hyser_original_experiment_scripts.zip` 只有 Hyser HiWA 脚本，没有 DAD、SA、WA 和两种HiWA的完整实现，故使用已核查的仓库源码及相应方法原始公开来源。所有适配和偏差如实公开。

## 数值审计及尚存局限

- **46条后验层级评分记录**：15条早期真正独立训练 +10条软温度实验+21条新基线运行；其中DAD五次参数完全相同，仅算一个独立解，SA仅一条确定性结果。
- 所有参考评分的簇级行列边缘最大误差低于 `3e-14`，簇内Q边缘最大误差低于 `1e-9`，簇级P定点更新最大残差低于 `1e-9`；每个训练R的正交误差均存档。
- 每条结果保存参考与原生分组的`T`、`J`、样本/组熵正则、16簇对成本C、组级P、每Q的形状、熵及最大边缘误差；**但未保存每条原训练的最后一轮局部Q**。五种seed=42的代表性后验Q和16簇对均另存 `Q_examples/*.npz`，其余按脚本可重建。完整Q目标是**后验全局R的再求解**，不等于原训练末轮局部P/Q/J。
- HiWA-SSC 的五个种子通过本轮预设 `ΔR≤0.01、共识≤0.01、边缘≤1e−6` 简化数值检查；HiWA-GMM 五个种子中三次达到180轮最大迭代，**未全部满足上述简化检查**。这些简化指标均不构成完整KKT验证或全局最优证明。
- 同一个25秒试次，只验证拟合内效果。五种子只检验初始化变化，不等于五个受试者。对比结果不能推广为“新方法必然优于现有所有方法”。
- 数值源于依据审计过的GCOT/HiWA源代码公式进行的本地移植，**不是原版MATLAB及Python包逐字节直接运行**。DAD-3D明确为适配方法。
