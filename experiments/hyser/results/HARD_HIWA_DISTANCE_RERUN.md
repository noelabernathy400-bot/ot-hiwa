# Hyser 真实样本 Hard HiWA 距离误差复跑（2026-11-17）

> **数据与代码等级**：本次数字来自真实 Hyser sample1，数值核心根据本仓库 `src/hiwa/hiwa.py` 转录，已保留相同 HiWA 公式与相同超参；由于计算环境无法直接拉取仓库源码，**并非直接 import 仓库文件**。为此新增了直接调用原类的标准复跑入口 `scripts/run_hard_distance_multiseed.py`，但它的真实运行结果尚未单独核验。请勿将这两个执行层次混淆。

## 1. 数据与特征

- 官方：PhysioNet Hyser v2.0.0 / `random_dataset/subject01_session1/sample1`。
- 肌电侧：256 通道、2048Hz，0.1s 窗口通道 RMS，经训练标准化和 PCA 变成 3D。
- 力量侧：100Hz 的 5 根手指实际力量，取训练期方差较大的 thumb/middle/index，变成 3D。
- 两侧各 250 个点；按时间前 200 点训练，后 50 点探索性留出；所有已知同步索引只用于结果评价与训练集 oracle，**从不参与 HiWA 求解**。
- 用两域各自的训练数据拟合对称协方差白化矩阵；**欧氏距离为此白化三维空间中的无量纲距离**，不能与牛顿、伏特混同。
- `K=4` 两边独立 K-means 硬分组（原始训练图见 `../figures/`）。

## 2. HiWA 设置

直接参考 `src/hiwa/hiwa.py` 的簇内 OT、簇级 Sinkhorn、局部旋转和 ADMM 数值更新：

```text
mu = 0.05
tol = 0.01 (both ||Rg(t)-Rg(t-1)||_F and max_ij ||Rij-Rg||_F)
maxiter = 200
shorn_gamma = 0.2, shorn_maxiter = 300
sa_maxiter = 40, sa_tol = 0.01
sa_shorn_gamma = 0.1, sa_shorn_maxiter = 80
X_transform = Y_transform = I_3
normalize = False (train whitening done externally)
```

嵌入量会按原公式再除以 `sqrt(3)`。随机种子预先固定 0–9，不能仅选效果最好的一次。

## 3. 距离误差：最重要的结果

每一真实同步窗口的评价距离为 `||R x_i - y_{pi(i)}||_2`；`pi` 来自隐藏的真实同步索引。对齐前取 `R=I`；oracle 只用训练集真配对拟合最优正交旋转，然后用于两集的**诊断下界**（不是无监督基线）。

| 指标（同步窗口平均欧氏距离，越小越好） | 训练集 | 同试次末尾 5 秒留出 |
|---|---:|---:|
| 对齐前（固定） | 1.9232 | 2.0850 |
| Hard HiWA 对齐后（仅 8 个收敛种子，mean ± SD） | **2.3492 ± 0.0670** | **2.1105 ± 0.1943** |
| 最优正交 oracle（使用训练期真配对） | 1.6530 | 1.9272 |

- 相比对齐前，**训练平均距离变大**，而留出距离也未明显改善。
- 留出 Top-1 检索 8 次收敛均值 **1.5%**，50 个候选的随机基线 **2%**；跨域簇一致率均值 **12.5%**。因此不能声称对齐成功。
- 训练集均值的相对 Frobenius 误差（收敛种子）约 **1.464**；同试次留出约 **1.936**。
- 留出中将真实配对随机打乱后的平均距离约 **1.991**，反而略低于 Hard HiWA 对应点距离 2.1105，进一步表明同步对应没有恢复。

## 4. 收敛性和参数敏感性

- `mu=.05`，seed 0–9 共 **8/10** 达到 ADMM 双残差 0.01；另两次运行满 200 轮仍不满足。
- 收敛者最终约 53–61 轮；见 [逐种子结果](hard_hiwa_distance_rerun.csv)。
- `mu=.02`，seed 0,1,2：**0/3** 收敛（200 轮）。
- `mu=.20`，seed 0,1,2：**3/3** 收敛（26–37 轮），但同试次留出平均距离约 2.308–2.380，反而比 `mu=.05` 的部分收敛种子更差。
- 固定 300 次簇级 Sinkhorn 的最大边缘误差一般约 `3e-4`；增至 3000 次，在 seed0 下降为 `6.0e-5`，没有使对应距离明显改善。**ADMM 双残差收敛不能代替 OT 边缘高精度收敛。**
- 这是非凸优化，不同种子存在不同结果，参数扫描仅用于解释训练数值状态，并未使用测试标签挑最优模型。

## 5. 研究判断

Hard HiWA 并非每次都数值失败：部分种子满足共识条件。**但恢复真实跨模态几何结构的任务目前没有成功**。Oracle 都有明显残差，可能表明 PCA 肌电坐标与三维真实手指力量之间不具近似等距关系；或者存在肌肉激活→输出力的时间滞后、信号非线性及测量噪声。证据不足以把问题归罪于硬分组边界。
