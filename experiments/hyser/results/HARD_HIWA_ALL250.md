# Hyser：全部 250 对真实样本的 Hard HiWA 一次性对齐（2026-11-17）

**按最新要求：不再分训练/留出。** 同一条 25 秒真实 Hyser sample1，分为 250 个 0.1 秒同步窗口，两个模态各 250×3，分别独立 K-means(K=4)，整组点一次性输入 Hard HiWA。同步关系只用于对齐结束后的误差评价。

肌电：256 通道窗口 RMS → log1p → 全 250 点通道标准化 → PCA(3) → 协方差白化。力量：选 thumb/middle/index 三指的窗口平均力量 → 全 250 点白化。两域都是无量纲坐标。

## 最新代码核对

截至 GitHub main 的 d99523709dfa703b121a7c35781296178fd7b530，src/hiwa/hiwa.py 的 blob 为 cf80120bc6e0e76fd257084f0540f9b7e9981484。求解器采用簇内 Sinkhorn/局部旋转、簇级 Sinkhorn、ADMM 共识。核心数值更新与之前本地转录版对照没有发现新的差异。

确认评价 bug：源码内部 _eval_R2 少了平方项，在中心化点云上可能输出虚假的 1.0；它不进入优化更新。以神经实验 src/cc_hiwa/common.py::original_r2 公式（平方误差）作为 R²，扩展到全部三个力量维度。源码 _rMSE 需要真实旋转 Rgt，真实 Hyser 没有 Rgt；下表用已知同步点配对的相对平方误差代替，不冒充真实旋转误差。

## 全部样本的计算结果

| 指标 | 对齐前 | Hard HiWA seed42 | 11 种子均值±样本SD | 正交 Oracle（使用已知配对，仅诊断） |

参数 K=4，μ=.05，ADMM tol=.01，外层上限 200；簇级 γ=.2 / 300 次 Sinkhorn，局部 γ=.1 / 80 次 Sinkhorn，局部交替 40 次。随机 seed42、0–9 共 11 次，**11/11 达到 ADMM 双残差阈值**。seed42 31 轮，最大局部共识残差 .009866，全局 R 变化 .000607。簇级 OT 边缘误差约 1e-4–4e-4；仍需高精度 OT 审计。

R² 的定义：1-SSE/SST；当平方误差大于目标总离差平方和时为负，**负数不代表代码必然出错**。本次全量白化目标的均值为 0，因此 R²=1-同步相对平方误差。内部旧代码直接显示 R²≈1 是评价公式错误，不能作为结论。

## 复现与限定

此前实际数值来自按当时 GitHub src/hiwa/hiwa.py 转录的数值等价本地代码，**不是克隆后字节级执行原文件**。本目录新增 scripts/run_all250_hard.py，直接 import 仓库 src.hiwa.hiwa.HiWA，作为可复现入口；复跑结果须再核对。使用官方 WFDB 文件四件（preprocess .hea/.dat，force .hea/.dat）；若下载成 random_force_sample1(1).dat，须改名 random_force_sample1.dat。
