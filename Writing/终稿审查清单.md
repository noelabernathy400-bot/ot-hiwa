# GC-HiWA 研究质量审查清单

审查日期：2026-07-25
审查范围：固定 Soft-GCOT / GC-HiWA 主干、ROCA、适用性诊断、合成边界实验和 Panoptic 受控验证。

## 结论

**阶段性风险：中等；若作为“真实跨设备语义动作迁移”论文终稿，风险为高。**

当前证据支持一篇以“带适用性诊断的无监督坐标对齐”为核心的论文或技术报告；不支持“GC-HiWA 已普遍提升跨设备动作识别”的结论。

## 硬性检查

| 维度 | 结论 | 证据或缺口 |
|---|---|---|
| 问题定义 | 通过 | 明确限定单一允许正交变换、共享群组结构、无标签和无配对。 |
| 数学可识别性 | 部分通过 | 正确耦合与满秩条件下有唯一恢复定理；完整 OT–ADMM 的全局收敛未证明。 |
| 方法边界 | 通过 | 固定 Soft-GCOT / GC-HiWA、ROCA 分支和弃权机制已分离；不把低 OT 成本写成语义恢复。 |
| 失效诊断 | 通过，但仅限当前协议 | 数值健康、拟合比、协方差谱和多启动稳定性均须通过。 |
| 合成恢复 | 通过 | 独立种子 1961–1965：三类可恢复条件 15/15 接受。 |
| 合成弃权 | 通过，但样本有限 | 五类违反合同条件 25/25 弃权；此前旧门槛的 1 次错误接受已完整保留。 |
| ROCA | 通过当前合成筛选 | 15/15 接受运行选择正确分支；未证明所有群组结构下均可识别。 |
| Panoptic 几何验证 | 通过，受控 | 多相机、无标定和无配对拟合下恢复物理旋转；多启动协议防止单次局部解。 |
| 下游任务 | 仅受控代理 | 已验证源定义姿态状态的冻结迁移；没有真实语义动作标签的跨设备结果。 |
| 可复现性 | 通过 | 114 项测试通过（受限 CPU 线程）；结果 JSON、固定种子、汇总器与冻结证据审计器均在仓库。 |
| 真实数据来源 | 部分通过 | Panoptic 可复查；跨设备语义动作主数据尚未取得。 |
| 引用与表述 | 有条件通过 | 仅保留官方数据页链接；终稿须补齐相关工作和数据集引用。 |

## 必改项：提交真实应用论文前

1. 取得可合法复查的带真实动作标签、至少两个坐标观测的数据集。
2. 按冻结的源设备训练／目标设备无标签对齐／目标测试协议运行。
3. 报告源模型直用、GC-HiWA 映射、标定或配对上界、接受率、弃权率与错误接受。
4. 以主体或采集会话划分，禁止随机帧泄漏。
5. 在独立真实数据上验证 \(\eta\) 与谱门槛的误拒绝和错误接受。

## 当前可安全写入的核心结论

GC-HiWA 在共享群组几何且存在单一结构化正交坐标关系的受控条件下，可以从无标签、无配对样本中恢复三维姿态坐标关系；其资格门槛在预设的错配、非正交和跨模态合成边界中会弃权。该结论不等同于对任意跨域任务或真实跨设备动作识别的普遍改进。
